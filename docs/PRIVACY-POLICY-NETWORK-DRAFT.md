# 星象仪隐私政策：联网版候选稿

> **状态：已被取代。** 2026-11-03 起，联网版政策正文以 `docs/PRIVACY-POLICY.md`（v2.0）为准；
> 本稿是 2026-09-08 的发布准备稿，仅作历史记录保留，内容不再随功能同步。

编写日期：2026-09-08。状态：发布准备稿，尚未生效；不能替换当前离线包对应的政策。本文件不声明备案已通过。运营者沿用 AGC 登记的杨杰轩，联系渠道沿用 AGC 已保存的隐私联系邮箱；不在公开仓库另行复制私人联系方式。

## 1. 适用范围与选择

星象仪提供本地星图、天体搜索、观测计算，以及按需启用的定位、设备转向和资源服务。不同版本开放的服务可能不同；下述联网条款仅适用于实际开放并由您选择使用的服务。未启用的服务不因此取得收集授权。拒绝可选功能所需的数据，不影响与其无关的本地星图功能。

我们按具体功能说明处理目的、数据种类、接收方、保存方式及关闭方法。涉及敏感个人信息、向其他个人信息处理者提供信息或跨境提供等情形时，依法履行相应告知、评估及单独同意等要求，不以接受本政策代替这些步骤。

## 2. 观测地点和设备朝向

### 自动定位

在您同意政策、主动点击自动定位并授予系统定位权限后，读取系统返回的经纬度及可用海拔，用于计算该地点的天空。仅在该次操作获取，不进行后台持续定位或轨迹记录。您可以拒绝定位，使用离线城市查找或手动选择观测地点；失败时保留原地点。

选定地点保存在设备本地，直至修改或清除应用数据。自动定位本身不向本应用服务器上传地点。若您另行使用天气等依赖地点的在线服务，将在该服务中确认所使用的地点及其接收方。模拟观测地点不一定是您的实际位置，二者不能混同。

### 转动设备浏览星空

同意政策并主动开启功能后，在前台读取设备支持的重力传感器三轴分量（稳定地平线）、磁场传感器三轴分量（方向校准）、旋转矢量（姿态计算）；必要时使用方向传感器方向角。系统融合过程可能使用加速度计、陀螺仪和磁场传感器。权限名称不能替代对这些具体数据的说明。

原始测量值仅在本机内存计算，不建立采样文件，不向本应用服务器上传。关闭功能、进入后台或撤回同意后停止订阅。常规诊断仅记录功能状态、次数和耗时，不记录原始重力、磁场或方向角。不开启此功能时可以使用触摸浏览。

## 3. 基础组件、SN 和 UDID

Qt 是星图运行和渲染的基础组件，初始化安排在同意当前政策之后。已经定位到上游 Qt 的设备信息批量初始化路径包含 serial（SN）和 udid 字段；审核也报告了 SN 相关调用。接口被调用、调用失败和实际取得标识是不同情况，不能把日志中没有序列号理解为没有调用。

**发布前核验项：** 最终发布包中 Qt 版本、具体请求字段、返回结果、缓存周期、调用必要性及组件是否外传仍须形成可验证结论。天文计算本身不需要 SN/UDID，不得为保留调用虚构广告、风控或望远镜连接用途。政策同意后调用只是时序限制，不能替代必要性审查。本条目前是整改记录，不是可直接发布的完整 SDK 告知。

## 4. 按需联网服务

以下为联网版拟采用的业务边界；每个服务上线前须完成接收方和保存期限清单，并使代码与说明一致。

| 功能与触发 | 必要请求内容 | 接收范围与控制 |
| --- | --- | --- |
| 主动更新 TLE、星表、流星雨、文化、地景、图片或模型资源 | 资源标识、版本、语言、分块或断点范围；连接产生的 IP、请求时间、响应状态及必要客户端兼容信息 | 官方资源服务、对象存储或 CDN；无需真实观测经纬度、原始传感器值或 SN/UDID。自动更新须另行开启，可关闭；不能默认恢复已拒绝的下载 |
| 主动在线天体查询、巡天图层或多波段图像 | 天体名称/编号、天球坐标、视场、波段或瓦片编号及网络连接信息 | 查询或图像提供方；天球坐标不同于地球经纬度，不额外发送实际定位 |
| 主动查询天气、光污染、海拔或附近飞机 | 经确认的观测地点或区域、查询时间、范围和连接信息 | 对应服务提供方；尽量使用满足用途的较粗区域。精确位置发送前说明必要性和影响并取得相应授权；可手动指定地区或不使用 |
| 手动添加外部 TLE、目录、脚本或资源网址并发起访问 | 您输入的网址和服务需要的查询参数；接收方可见连接 IP | 直接来源不等于我们的境内镜像。显示真实域名及第三方说明；境外来源不自动访问，跨境要求未满足时保持禁用，可改用本地文件。拒绝后不偷偷改走其他服务器 |
| 主动提交故障反馈 | 您确认提交的问题描述、联系方式、版本、错误信息及所选附件 | 反馈接收服务；提交前检查和脱敏，不自动上传整个日志目录、观测历史、凭据或序列号 |

网络请求本身会暴露 IP 等连接信息，即使只下载公开星表也不能称为完全不处理个人信息。下载失败保留已有离线数据，显示错误、数据时间和重试入口，不通过无限重试扩大请求。

不要在来源 URL 中嵌入账号密码、长期令牌或私人位置。第三方网址可能转向其他主机；应在实际访问前处理接收方变化。通过我们服务器代理的请求和直连第三方的请求必须分别说明，不能统一承诺全部数据只在境内流转。

## 5. 本地文件、相册、剪贴板与分享

配置、观测列表、脚本、会话和下载资源保存在本机。导入时只处理您通过系统选择器选定的文件或明确授权的目录，用于恢复配置或加载相应内容，不遍历无关私人文件。导入脚本和插件不因导入即获得定位、网络或文件权限。

截图及视频保存、配置/会话导出和分享只在您主动操作时进行。输出可能包含观测地点、模拟时间、视角和您添加的文字，请在分享前检查。复制导出文本时写入系统剪贴板，不以此读取其他剪贴板内容。导出文件、相册内容和剪贴板由系统管理；清除应用数据不会同时删除这些副本，您需在相应位置清理。

通过系统分享选择的应用或外部浏览器由其服务提供方处理数据，适用相应隐私规则。当前本地保存不能被描述成已具备云备份。

## 6. 望远镜、多设备和命令控制

模拟望远镜在本机运行。实际设备连接由您填写并确认地址和端口后发起，处理目标赤经赤纬、设备返回的指向、连接状态及控制指令；不因此需要读取手机 SN，也不自动扫描或公开家庭网络。

多设备会话若启用，仅向您确认的接收端传递明确选择的观测时间、位置、视角和显示配置。命令行控制与界面操作遵守相同的隐私和权限限制。向远程控制端或 AI 服务提供操作权限、上传日志或同步资料须分别授权；本地 CLI 不等于授权任意第三方远程访问。

蓝牙、星闪、云端设备同步等尚未验证的能力不在本稿中宣称已启用。其接收方、标识、权限、配对及撤销机制完成后另行告知。

## 7. 设备权限

| 权限或系统能力 | 使用时机与用途 | 拒绝或关闭 |
| --- | --- | --- |
| APPROXIMATELY_LOCATION / LOCATION | 主动自动定位，取得粗略或精确观测地点 | 保留手动选点，不进行后台定位 |
| ACCELEROMETER / GYROSCOPE 及姿态传感器接口 | 主动开启设备转向，完成方向与地平线计算 | 触摸浏览仍可用，关闭及后台停止订阅 |
| 文件选择器、保存和分享能力 | 用户选择导入、导出、保存相册或分享 | 不自动访问未选择文件；以实际 API 核验是否还需额外权限 |
| INTERNET（联网包） | 仅已开放且由用户选择的在线服务 | 当前离线包不增加该权限；联网权限存在不代表所有服务获得个人信息授权 |

当前未实施的相机、麦克风、通知、蓝牙等权限不预先声明为正在申请。天象提醒若仅本地计算和通知，不能把它写成服务器推送；推送服务上线前另行说明推送标识、接收方和关闭方式。

## 8. 第三方与存储安全

本地姿态和观测计算不因联网而自动上传。联网版由我们提供的资源服务拟部署在中国境内（不含中国香港特别行政区、中国澳门特别行政区和中国台湾地区）；服务商、区域及 CDN/对象存储合同确定后，在发布清单中列出实际主体和用途。用户选择的外部来源不适用这一境内存储承诺。

对于受托处理者，将约定处理目的、期限、方式、信息种类和保护措施并监督履行。对于独立处理者，依法告知接收方名称、联系方式、目的、方式和种类，并取得所需单独同意。涉及跨境时，完成适用的法定程序后才启用对应路径。

拟采用加密传输、最小运维权限、日志脱敏、访问审计、备份保护及到期删除。上线前须实测这些控制，不以“绝对安全”作保证。发生个人信息安全事件时依法处置并履行通知义务。

保存规则：姿态测量仅用于当次实时计算；本地地点、列表及配置至用户修改或清理；导出副本由用户控制。网络安全日志、故障反馈及第三方缓存分别根据用途和适用法定义务确定最短必要期限，到期删除或匿名化。**具体期限、删除任务和备份清理尚未确认，不能直接以本段替代发布前的留存清单。**

## 9. 您的权利与未成年人

可在位置页查看和修改观测地点，在系统应用设置管理权限和清除本地数据，在应用“设置—设备与隐私”撤回同意。撤回后停止姿态订阅并退出，再次启动须确认政策；对过去基于同意合法进行的处理不产生追溯影响。联网版还应停止依赖被撤回同意的下载、查询及远程连接。

您可通过 AGC 政策中提供的隐私联系邮箱要求查阅、复制、更正、删除个人信息，撤回同意或获得处理规则解释。只为核实请求进行必要身份验证，不默认索取身份证照片或设备 SN。无法满足请求时说明理由和投诉途径。无需账号的版本不存在账号注销步骤，不能让用户寻找不存在的注销入口。

未满十四周岁儿童使用涉及个人信息的服务前，应由监护人阅读专门的儿童个人信息处理规则并依法给予同意。相关监护人同意机制和儿童规则未经实现、核验前，不将其写成已经具备；不能仅以“建议家长指导”代替法定要求。

## 10. 变更及发布

新增业务在启用前核对实际数据处理并更新说明；重要变更以醒目方式告知，需要重新取得同意或单独同意的先取得相应授权。仅增加预研文字不自动开放功能。

账号登录、内购、云同步、远程图片解析、云端 AI 和用户投稿目前仅作后续规划，不预先要求提供身份证、支付信息、照片或通讯录。这些功能确定后编写独立业务清单，不用“未来可能收集任何必要信息”覆盖。

正式生效日期以完成审核并与对应发布版本一致的政策为准。本稿的编写日期不是生效日期，也不构成已经备案、审核通过或已经联网的证明。
