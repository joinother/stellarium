# Stellarium 隐私政策

**最后更新日期：** 2026-07-27

Stellarium 是一款开源天文软件，基于 GPLv2 许可证发布。我们高度重视您的隐私。本隐私政策说明应用如何处理您的信息。

---

## 1. 我们不收集的信息

Stellarium **不收集、不存储、不上传**任何用户个人信息。具体而言：

- 不收集用户身份信息（姓名、邮箱、电话等）
- 不收集设备标识符
- 不上传任何数据到我们的服务器
- 不包含任何第三方广告 SDK 或追踪 SDK
- 不进行用户行为分析或统计

## 2. 应用使用的设备功能

### 2.1 位置信息（ohos.permission.LOCATION / APPROXIMATELY_LOCATION）

- **用途：** 用于将星图与您的观测位置匹配，显示当前位置可见的天体
- **获取时机：** 仅当您在应用内主动点击"自动定位"时获取
- **存储方式：** 位置数据仅保存在您的设备本地，不上传任何服务器
- **可拒绝：** 您可以拒绝位置权限，手动输入城市名或经纬度

### 2.2 加速度计和陀螺仪（ohos.permission.ACCELEROMETER / GYROSCOPE）

- **用途：** 用于"陀螺仪模式"，根据设备朝向调整星图视角
- **获取时机：** 仅当您主动开启陀螺仪功能时使用
- **存储方式：** 传感器数据实时处理，不存储不上传

### 2.3 文件存储（ohos.permission.STORE_PERSISTENT_DATA / FILE_ACCESS_PERSIST）

- **用途：** 保存应用配置、观测列表、截图等用户数据到设备本地
- **存储位置：** 仅存储在应用沙箱目录内
- **不上传：** 所有文件数据仅保存在本地设备

## 3. 离线运行说明

Stellarium 上架版本（v1.0）为**完全离线版本**：

- 不申请网络权限（ohos.permission.INTERNET）
- 不进行任何网络通信
- 所有天文计算和数据均在本地完成
- 不包含星表下载、卫星数据更新等联网功能

## 4. 开源透明

Stellarium 基于 GPLv2 开源许可证，完整源代码公开于：

https://github.com/joinother/stellarium/tree/openharmony-preview-v1

任何人都可以审查源代码，验证本隐私政策的声明。

## 5. 儿童隐私

Stellarium 是天文教育类应用，适合所有年龄段使用。我们不收集任何个人信息，包括儿童的个人信息。

## 6. 隐私政策变更

如果本隐私政策发生变更，更新后的政策将在应用内或本页面发布，并更新"最后更新日期"。
