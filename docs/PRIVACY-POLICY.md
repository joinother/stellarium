# 星象仪 (Stellarium) 隐私政策

**版本：** 2.1
**最后更新日期：** 2026-11-26
**生效日期：** 2026-11-26
**适用应用：** 星象仪（HarmonyOS，包名 `com.joinother.skyinstrument`）
**修订说明：** 本版与华为 AppGallery Connect 托管隐私政策（`agreementId=2092220462707776256`，`versionCode=3`）保持完全一致：在 2.0 联网版基础上，补齐 AR 实景星空相机权限（`ohos.permission.CAMERA`）、多光谱在线高清巡天瓦片（HiPS）、境内镜像小行星/彗星（MPC）目录同步、华为地图服务（Map Kit / Site Kit）与外部地图跳转、`surl.amap.com` 短链单次解析、网络状态与触觉反馈权限说明，以及跨境传输与服务器日志 180 天留存披露。

星象仪基于 Stellarium 开源项目，遵循 GPLv2 许可证。星图计算在设备本地完成。本应用**不需要注册账号，不采集设备唯一标识，不接入广告或第三方统计 SDK，不建立用户画像**。主动使用定位、设备转向、AR 实景相机、在线地图、按需数据更新、保存和分享时，会在本机处理下述数据，或在您触发时访问网络。

"不上传"不等于"不读取、不处理"；"不采集"也不等于"不产生网络连接信息"。下面逐项说明。

## 1. 观测地点

- **用途和数据：** 读取系统提供的经纬度及可用海拔，用于计算当前地点可见的星空。
- **获取时机：** 同意隐私政策后，主动点击自动定位并授权定位权限时获取一次。相关权限为 `ohos.permission.APPROXIMATELY_LOCATION` 和 `ohos.permission.LOCATION`。
- **控制：** 拒绝或获取失败时保留原观测地点，可继续使用内置城市列表和手动选点；不后台持续定位，不建立位置轨迹。联网且启用华为地图时，可能将选定或定位坐标发送至华为地点服务做单次反向地理编码，仅用于展示所属行政区简称。
- **保存：** 选定地点保存在设备本地，不向本应用自有服务器上传。清除应用数据可删除本地保存的地点；自行导出的文件需另行删除。

## 2. 设备姿态传感器

"转动设备浏览星空"与"AR 实景星空"功能根据设备支持情况读取以下类型的数据：

- **重力传感器：** 三轴重力分量，用于辨别设备上下方向、稳定地平线。
- **磁场传感器：** 三轴磁场分量，用于罗盘方向校准。
- **旋转矢量传感器：** 旋转分量，用于计算设备姿态并调整星图视角。
- **方向传感器：** 在旋转矢量不可用时提供方向角，用于设备朝向计算。
- 系统融合姿态数据可能使用加速度计、陀螺仪和磁场传感器。

**获取时机：** 同意本政策后，主动开启上述功能时订阅。关闭功能、进入后台或撤回同意时停止订阅；不开启时仍可通过触摸浏览星图。

**处理方式：** 测量值在本机内存实时计算，不建立传感器采样文件，不向本应用服务器上传。常规姿态诊断仅保留功能状态、调用次数等信息，不记录原始方向角、重力或磁场测量值。主动导出配置、会话或诊断资料时，请检查其中包含的观测位置和视角等内容后再分享。

## 3. AR 实景星空相机

- **用途和数据：** 读取后置摄像头实时预览画面，在本机 GPU 纹理中与实时星图叠合显示。
- **获取时机：** 仅在您同意本政策并主动点击开启"AR 实景星空"时向系统申请 `ohos.permission.CAMERA` 权限，绝不在启动期静默申请。
- **处理与边界：** 相机预览帧全程仅留在本机内存与 GPU 纹理做实时融合渲染，**不拍照、不录像、不写入本地存储、不上传任何服务器**。关闭 AR、切换至后台、页面销毁或撤回权限时，立即停止相机会话并释放资源。拒绝权限不影响普通星图浏览。

## 4. 设备序列号（SN）及基础运行组件

星图、观测地点、AR 实景和设备转向功能不需要以硬件序列号识别用户。应用不以设备标识建立用户画像或进行广告追踪。基础运行组件初始化仅允许在同意当前隐私政策后执行。

Qt 6.12.0 基础运行环境用于承载本地星图引擎、图形显示和操作系统适配。其初始化通过系统设备信息接口尝试读取操作系统及软硬件参数，包括设备序列号（SN）和 UDID；是否返回有效值由系统权限控制。本应用不增加受限设备标识权限，不向本应用服务器或组件提供方上传这些字段。该调用属于同意当前隐私政策后的 SDK 初始化，不是连接外设时才调用，星图计算本身不依赖硬件标识。

设备信息在本机运行上下文处理；系统拒绝返回时，不将接口调用描述为成功取得标识。上游组件信息：[Qt](https://www.qt.io/)，提供方隐私说明：[The Qt Company](https://www.qt.io/terms-conditions/privacy-policy)。上述链接不代表本应用接入其广告或统计服务。

## 5. 按需联网服务

本应用**不存在后台静默联网**。所有联网行为均由您的主动操作触发，或由您在"卫星"面板主动开启的更新周期触发（默认关闭，可改可关）。联网只发生以下几类请求：

| 触发方式 | 请求内容 | 目的地 | 对方可见 |
| --- | --- | --- | --- |
| 刷新卫星目录 / 同步小行星与彗星目录 | 公开清单与只读数据路径（如 `/v1/manifest.json`、`/v1/catalogs/satellites/*`、`/v1/catalogs/mpc/*`），无账号、无位置 | `skyinstrument.cn`（本项目境内镜像，阿里云中国上海） | 您的 IP、请求时间、请求路径、状态码、响应字节数 |
| 主动开启多光谱全天巡天，或在放大镜静止且视场放大至 `<14°` 浏览深空高清细节 | 公开巡天 `properties` 与当前视场天区瓦片路径（无账号、无位置） | `hips.china-vo.org`（中国虚拟天文台，境内）；`skies.esac.esa.int`、`erosita.mpe.mpg.de`、`data.stellarium.org`（境外） | 您的 IP、请求时间、请求路径（可推断所浏览的公开天区） |
| 点"下载"安装扩展星表 | 星表文件标识与标准 HTTP 请求头（无账号、无位置） | `sourceforge.net`（Stellarium 官方扩展数据，境外） | 您的 IP、请求时间、请求路径 |
| 卫星/小行星目录中手动保留或添加境外上游源并刷新 | 公开目录文件路径（无账号、无位置） | `celestrak.org` / `amsat.org` / `mmccants.org` / `minorplanetcenter.org`（境外） | 您的 IP、请求时间、请求路径 |
| 分享含高德短链且无离线坐标的文本到星象仪 | 单次无重定向（`maxRedirects=0`）HTTPS GET，仅读取白名单 `*.amap.com` 的 `Location` 响应头 | `surl.amap.com`（境内） | 您的 IP、短链路径与标准请求头 |

**跨境传输：** `sourceforge.net`、`skies.esac.esa.int`、`erosita.mpe.mpg.de`、`data.stellarium.org`、`celestrak.org`、`amsat.org`、`mmccants.org`、`minorplanetcenter.org` 位于中国境外（美国及欧洲地区）。触发上述下载或高清巡天浏览时，请求会携带网络连接所需的 IP 地址与标准 HTTP 请求头传输至境外，并由这些站点按其自身隐私政策处理。**若您不希望发生跨境传输，请勿触发扩展星表下载、境外多光谱高清瓦片或境外目录源**；随包内置的星表、4K 离线多光谱全景、行星与深空底图及卫星/小行星快照不受影响，断网仍完整可用。

**失败处理：** 下载失败时保留已有本地数据，显示错误原因、数据时间与重试入口，不进行无限重试。

## 6. 无线控制（局域网服务）

- **默认关闭。** 只有您在"设置 → 无线控制"中打开后，应用才会启动一个本地 HTTP / WebSocket 服务（默认端口 8090），监听本机局域网网络接口。
- **作用范围仅限局域网。** 同一 Wi-Fi / 热点下的其他设备（例如您的电脑浏览器）可访问该端口操作星图。该服务不经过任何云端、不连接本应用服务器、不上传任何内容。
- **访问控制。** 默认不设密码；同一局域网内的设备可以直接访问。请在可信网络中使用；公共 Wi-Fi 下建议保持关闭。该能力支持设置访问密码（由内置 RemoteControl 模块提供）。
- **可随时关闭。** 关闭开关立即停止监听；应用退出后服务随之停止。
- **不记录访问者。** 该服务不保存访问者 IP、请求内容或操作历史。

## 7. 华为地图服务与外部地图跳转

- **华为地图（Map Kit / Site Kit）：** 位置页提供离线地图与华为地图能力，断网或加载失败自动回退随包离线地图。在已同意隐私政策、位于地球且网络可用时，位置概览卡、全屏选点地图、主动输入地点关键词搜索（`site.searchByText`）及单次坐标反向地理编码（`site.reverseGeocode`，仅显示行政区简称）会调用华为地图服务。提供方为华为软件技术有限公司，详情见[华为地图服务个人隐私说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/map-personal-privacy)。本应用不附加 SN、UDID、账号或观测历史，也不建立自有轨迹；文化分布图继续使用本地研究叠加层。
- **外部地图跳转与地点分享：** 用户主动点击"规划路线"时调用系统统一导航选择面板，点击"查看地点"可跳转花瓣地图、百度地图或系统支持的其他 `geo:` 应用。工程中声明的 `querySchemes`（`petalmaps`、`baidumap`、`geo`）仅用于本机 `bundleManager.canOpenLink` 判断对应地图应用是否已安装，**不扫描已安装应用列表，也不读取其他应用的包信息或图标**。跳转仅传递您选定的目标名称与经纬度，外部地图应用适用其自身隐私政策。

## 8. 本地保存、导出和分享

配置、观测列表等默认存储在应用沙箱；主动保存到相册、选择导出目录或分享时，按系统选择结果交给相应位置或应用。本应用不自动上传这些文件。接收应用如何处理分享内容，适用其隐私规则及您的后续操作。清除应用数据可删除沙箱资料，相册和导出文件需在对应位置另行删除。

主动导入仅处理用户选定的文件（星表、TLE、脚本、贴图）。主动点击复制时向系统剪贴板写入所选内容，不因剪贴板变化通知自动读取其中内容。分享配置、会话或诊断资料前，请确认其中包含的观测地点、视角等信息。

## 9. 望远镜与多设备

模拟望远镜在本机运行。实际设备连接由您填写并确认地址和端口后发起（LX200 / RTS2，通常在局域网内），应用处理目标赤经赤纬、设备返回指向、连接状态与控制指令；**不自动扫描、不广播、不公开家庭网络**，也不因此读取 SN。该功能不经过本应用服务器。

多设备会话若启用，仅向您确认的接收端传递您明确选择的观测时间、位置、视角与显示配置。

## 10. 通知、提醒与触觉反馈

- **天象提醒：** 如您主动开启天象提醒，应用仅把您选择的标题、内容和事件时间交给鸿蒙系统本地代理提醒服务（`ohos.permission.PUBLISH_AGENT_REMINDER`），由系统在设备上本地触发显示；不读取或上传 SN、位置信息，不使用自有应用服务器推送。可在系统通知设置中关闭，或在应用内清理已注册提醒。
- **触觉反馈：** 使用系统振动权限（`ohos.permission.VIBRATE`）在交互操作时提供轻微触觉反馈，可在应用设置中随时关闭，不涉及任何个人信息收集。

## 11. 权限清单

| 权限 | 用途 | 拒绝或关闭后的影响 |
| --- | --- | --- |
| `ohos.permission.INTERNET` | 按需刷新卫星/小行星目录、加载多光谱高清瓦片、下载扩展星表、使用华为在线地图 | 无法在线更新或加载在线地图/瓦片；离线星图与随包数据不受影响 |
| `ohos.permission.GET_NETWORK_INFO` | 检查网络连通状态以在在线华为地图与离线地球底图间切换（不读 SSID 或通信内容） | 按离线底图处理 |
| `ohos.permission.LOCATION` / `APPROXIMATELY_LOCATION` | "自动定位"单次获取当前观测点坐标 | 改用内置城市库或手动选点 |
| `ohos.permission.CAMERA` | "AR 实景星空"后置相机实时预览与星图本地 GPU 融合（不拍照录像、不上传） | 无法开启 AR 实景模式；普通星图正常 |
| `ohos.permission.PUBLISH_AGENT_REMINDER` | 本地天象提醒 | 无法注册提醒；其余功能正常 |
| `ohos.permission.VIBRATE` | 交互触觉反馈 | 无振动反馈；其余功能正常 |

敏感权限（位置、相机）均由系统弹窗在您主动触发对应功能时逐项授权，可随时在系统设置中撤回。

## 12. 存储地点与保留期限

1. 本地数据保存在应用私有目录，不随账号同步、不上传云端；清除应用数据或卸载应用即删除（重装后为初始状态）。
2. 境内镜像服务器（`skyinstrument.cn`，阿里云中国上海）记录访问日志：IP 地址、访问时间、请求路径、响应状态、响应字节数。日志按日轮转，**保留 180 天**，仅用于安全防护与故障排查，不用于广告画像，不与其它数据关联。服务器不接受上传，仅允许 GET/HEAD 只读请求，并启用 HTTPS。
3. 服务器不保存您的观测位置、设备标识或应用内数据。

## 13. 我们不做的事

- 不采集 IMEI、OAID、MAC、SN、UDID 用于识别或追踪（SN 仅在 Qt 初始化时按系统权限尝试读取，不上传、不落盘）；
- 不接入第三方统计、埋点、广告、商业推送 SDK（华为系统级本地提醒与地图服务除外）；
- 不读取通讯录、短信、相册（主动导入/保存由系统选择器授权除外）、麦克风；不上传相机画面；
- 不扫描已安装应用列表，不做用户画像、个性化推荐、跨应用追踪；
- 不在后台静默联网，不在您拒绝后改走其他服务器偷偷下载；
- 不出售、不共享您的个人信息给任何第三方（法定情形除外）。

## 14. 未成年人

儿童使用定位、相机和分享功能时建议由监护人指导。本应用不面向 14 周岁以下儿童单独提供服务，不进行广告追踪或用户画像，也不主动收集儿童个人信息。监护人如有疑问，可通过第 16 节方式联系。

## 15. 您的权利与隐私选择

- **访问与更正：** 观测地点、收藏、偏好可在应用内直接查看和修改。
- **删除：** 应用内删除收藏/观测记录，或清除应用数据/卸载应用删除全部本地数据。
- **撤回同意：** 入口为"更多 → 设置 → 设备与隐私 → 撤回隐私同意"；撤回后应用停止姿态订阅并退出，下次启动重新征询。
- **拒绝联网与关闭权限：** 不点击在线更新即离线可用；也可在系统设置中单独关闭联网、位置、相机或通知权限。
- **关闭无线控制：** 设置中随时关闭，服务立即停止监听。

政策更新涉及已同意内容变化时，通过华为应用市场隐私管理服务更新版本并重新取得相应同意。我们将在收到请求后 15 个工作日内答复。
