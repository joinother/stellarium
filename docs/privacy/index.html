星象仪 (Stellarium) 隐私政策

最后更新日期：2026-08-06

数据收集

本应用不收集、不存储、不上传任何用户个人信息，不包含广告或第三方追踪 SDK。

设备序列号（SN）和外接设备标识

本应用不读取、存储或上传手机硬件序列号（SN）。仅在您同意本政策后，并主动连接外接观测设备或定位设备时，系统或连接组件可能提供有限的外设标识（审核中可能被归类为 SN），其仅用于当前设备的本机连接和故障排查，不会保存、上传或用于追踪；不连接外设时不会触发此处理。

权限使用

定位权限仅在用户主动使用自动定位时用于本机匹配观测地点。加速度计和陀螺仪仅在用户主动开启相关功能时用于调整星图视角。相关数据仅在设备本地实时处理。

离线运行

上架版本不申请网络权限，不进行网络通信。观测地点、书签和设置仅保存在设备本地。

开源许可

本应用基于 Stellarium 开源项目，遵循 GPLv2 许可证。完整源代码见 GitHub。

联系我们

如有隐私相关问题，请通过 GitHub Issues 联系我们。
