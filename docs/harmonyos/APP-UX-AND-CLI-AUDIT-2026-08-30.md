# 全软件业务、操作与动画审计（2026-08-30）

## 结论

- 当前主流程已经收敛为“星图 + 底部 Dock + 单一面板状态机”：搜索、时间、位置、图层、更多是稳定入口；手机只改变面板呈现，不再恢复旧的 iPad 左侧菜单。
- 天体选择流程应保持单一事实源：星图/搜索/脚本/CLI 都写入同一选中天体；详情卡只展示这一选择，居中是一次性动作，屏幕锚定是持续动作，不能因面板变化再次移动天体。
- 资源流程应区分“文件存在”和“已经可显示”：离线文件、纹理准备、纹理解码失败、没有匹配资源分别反馈，不用空白或提前消失代替状态。
- 插件入口只管理插件元数据、加载策略和插件专属工作区；已被主界面吸收的能力不再复制一个第二开关。原生插件作者、许可证、来源和说明继续保留。

## 本轮 CLI 与交互复核

- 平板 `192.168.1.30:33805` 覆盖安装最新 HAP 后，CLI 基础回归为 `19/19`；位置、时间、图层、星空文化、资源状态、搜索、详情和清理选择均可响应。
- 追加的 28 项只读/低风险业务批量回归为 `28/28`；用 `getLocationList` 查询 `Beijing` 返回 9 个离线地点，卫星快照返回 3134 项，`Scenery3d` 动态加载、查询、卸载链路通过。
- CLI 烟雾脚本现在兼容位置参数和 `--device` 两种调用方式；之前误传 `--device` 会被当作设备 ID 的问题已消除。
- 检查脚本报告 `CompileArkTS`/HAP 构建通过；设备日志未出现 `AppFreeze`、崩溃或命令桥错误，渲染约 30 FPS。当前仍不能把 30 FPS 宣称为 100 FPS，需另行改造 Qt/OpenGL 与 ArkUI 的帧提交链路。
- 语言审计仍提示 636 个自定义 UI 条目至少在一种语言中等于英文；本轮只修复交互色板、圆角、轻触反馈和过渡，不伪称 43 种 ArkUI 文案已完成母语审校。

## 已发现并处理

### 资源与详情

- 深空图片状态探针补充稳定的 `ready`、`loading`、`notStarted`、`decodeFailed`、`noMatch` 状态；保留本地文件统计和纹理实际就绪统计。
- 星座艺术状态同样返回稳定状态，并区分“文件已在本地但尚未进入纹理上传”与“没有资源”；这避免把 `idle` 误判为损坏。
- ArkTS 深空状态观察从固定 3.5 秒改为无重叠的分段轮询：前段快速刷新，后段低频等待，最多约 24 次；达到上限时明确显示“仍在后台准备”，不再静默消失。
- 卫星目录健康信息保留具体来源错误。当前历史快照的主 CelesTrak 地址返回 HTTP 403，补充源仍可提供有效条目，因此状态是 `attention`，不是数据为空。

### 星空文化选择器

- 类型和地区选择器使用同一套面板表面、标题、选中颜色、边框和圆角；横向排列时各占等宽，避免一个选择器挤压另一个。
- 打开、关闭、选中使用一致的弹簧过渡；选中后先以动画收起，再写入筛选值，避免瞬间跳变和底图叠压感。
- 当前文化、星座艺术预览和文化说明仍使用独立资源生命周期，切换文化时通过请求代际丢弃旧结果。

## 动画规范

| 场景 | 动画策略 | 禁止事项 |
| --- | --- | --- |
| Dock 打开/关闭面板 | 统一弹簧位移动画 | 不重复创建左右两套面板 |
| 选择器展开/收起 | 透明度 + 轻微垂直位移 + 选中背景过渡 | 不使用透明浮层覆盖底图 |
| 详情卡拖动 | 直接跟手；连接线同步几何更新 | 不因 UI 变化重新避让或移动天体 |
| 详情页栏目切换 | 内容淡入/短位移 | 不阻塞实时坐标刷新 |
| 脚本播放控制条 | 仅显示简化控制条，状态切换有短过渡 | 不和普通帧定时器重复绘制 |
| 实时坐标、恒星时、时间数值 | 直接刷新 | 不做逐字或大幅布局动画 |

## 仍需后续处理

- 43 种语言中仍有大量通用 ArkTS 文案待进入资源表；优先处理 Dock、脚本控制、星空文化筛选和详情状态。
- 平板当前 CLI 可用且帧率约 27–30 FPS；“100 FPS 以上”受现有跨 Qt/OpenGL/ArkUI 回读链路限制，需单独评估原生 Surface/纹理共享方案，不能用降低画质换取数字。
- 插件/脚本的导入、签名和联网边界已在菜单审计中记录；本轮不修改联网策略、隐私/SN 或签名配置。
