# 联网功能本地化逐项矩阵

更新时间：2026-09-30

## 先说结论

当前工程的联网构建已经打开 `ohos.permission.INTERNET`、CMake 联网分支和华为地图代码路径，但这不等于所有服务已经部署或可以默认使用。官网 `https://skyinstrument.cn` 当前只有官网静态站点；`/v1/catalogs/...`、`/v1/health` 等资源服务路径实测为 404，因此不能把官网当成已经完成的资源镜像。

本矩阵把“本地化”拆成四种情况：

1. **随包本地化**：静态目录、流星雨、基础星表、文化、地景和模型直接进入 HAP，断网仍工作。
2. **境内静态镜像**：服务器只分发版本化静态文件，客户端显式更新，带哈希、签名、大小限制和旧版本回退。
3. **受控在线查询**：用户主动提交查询或浏览巡天，外发字段单独告知；不能用缓存冒充完整本地化。
4. **本地设备能力**：系统定位、通知、望远镜和局域网控制不需要公网镜像，按设备权限和本地连接治理。

权威逐项数据在 `data/ohos/network-localization.json`，审计命令为：

```bash
node scripts/check-ohos-network-localization.mjs
```

## 当前可直接本地化

| 能力 | 当前状态 | 做法 |
| --- | --- | --- |
| 卫星 TLE 四个来源 | 已随包 | 使用内置 `satellites.json`；后续只把更新包放在境内 HTTPS 静态镜像，保留历元、哈希和过期提示 |
| 系外行星、流星雨、新星、超新星、脉冲星、类星体 | 已随包 | 构建机更新后重新打包，运行时不依赖网络；镜像仅用于构建输入或用户主动更新 |
| 深空目录、高清图、行星纹理、地景、天空文化、脚本和模型 | 随包/本地导入 | 不需要联网；缺资源按资源审计修复，不以远程 URL 掩盖缺失 |
| MPC 静态轨道资料 | 构建期/本地导入 | 保留本地文件导入；确认授权后再使用境内版本化镜像 |
| 本地通知、节气提醒、LX200/OnStep、星闪预留 | 本地设备 | 不通过服务器转发；通知用系统能力，望远镜限制为本机、串口、私网或星闪 |

## 仍不能“一键本地化”的能力

| 能力 | 当前状态 | 原因与处理 |
| --- | --- | --- |
| HiPS/DSS 在线巡天、多光谱瓦片 | 用户主动联网，待镜像 | 必须同时镜像目录、properties、缩略图和多级瓦片，并确认数据授权；单换域名不算本地化 |
| SIMBAD、AAVSO、GCVS、在线系外行星查询 | 用户主动联网，待受控查询 | 需要查询词外发提示、缓存、限流和超时；不能做任意 URL 代理 |
| 实时 ADS-B 飞机 | 暂不接入 | 需要实时数据许可、费用、位置外发评估；静态镜像不能替代实时航迹 |
| Plate Solver 图片解算 | 暂不默认开启 | 会上传用户图片，必须单独同意、清理 EXIF、限制大小和说明保留期；本地导入仍可用 |
| IP 自动定位 | 关闭 | 直接外发公网 IP；使用系统定位或手动位置 |
| 华为 Map Kit | 代码路径存在，Profile/真机服务待验收 | 只用于用户主动位置选点，文化研究地图继续使用本地资料；失败回退离线地图 |
| 华为 Push、实况窗、锁屏/待机卡片、接续 | AGC/Profile/服务端待联调 | 不是普通资源镜像；分别需要能力审批、Profile、令牌或生命周期设计 |
| 应用内购 | 协议/商户/服务端流程待联调 | 需要华为订单校验和权益服务，不能把支付能力当成资源下载开关 |
| RemoteControl/RemoteSync/望远镜网络控制 | 本机/局域网 | 不部署公网端口，不把设备地址或控制命令发送到资源服务器 |

## 服务器现状

- 官网 `https://skyinstrument.cn` 已可访问，AppGallery 入口是用户主动点击的外部跳转。
- 资源镜像接口尚未部署：`/v1/catalogs/satellites/stations.3le`、`/v1/catalogs/exoplanets.json`、`/v1/health` 当前返回 404。
- 因此现在应把“联网构建”理解为**可以开始分项联调**，而不是把 22 个数据源或所有华为服务全部打开。
- 第一批建议部署：卫星 TLE 与六类小型 JSON 的版本化静态目录；第二批再评估小范围 HiPS/DSS；天气、ADS-B、在线查询、照片解算和 Push/IAP 单独立项。

## 每个服务上线前的门禁

必须同时满足：来源许可明确、HTTPS 白名单、用户主动触发、隐私同意已完成、外发字段已登记、超时/断网回退可用、大小与哈希校验通过、旧快照可恢复、Pad 真机验证完成。任何一项不满足，都继续使用随包资源或显示“暂不可用”，不伪造加载成功。
