# 动态雾山地景

## 设计与边界

- 参考用户录屏 `ScreenRecording_09-08-2026 14-34-49_1.MP4` 中层叠远山与流雾的视觉方向，自行编写程序化效果，不提取其他应用的图像资源。
- 入口：图层 → 地景 → 动态雾山地景。首次没有照片地景、也没有雾山偏好记录时默认启用；保留已有照片模式。用户明确关闭后不再自动打开。
- 地面与雾山开关互斥：开地面关雾山，开雾山关地面及三维场景，两项都关为无地景。照片模式开启时清零雾山透明度；地面关闭时不绘制当前/旧照片地景及其雾效，避免缓存资源淡出时短暂出现。不需要重启或重新载入插件。
- 关闭地面后仍允许预选照片资源，但不显示、不改变观测位置。开启地面后使用已选资源；UI 明确提示“仅预选”。雾山配色独立于照片资源的亮度配置。
- 五层轮廓使用天球地平坐标，远山固定、近雾缓慢变化，跟随星图投影、视角、FOV 和翻转，不是盖在屏幕上的固定图片。轮廓为多尺度周期随机高度，层间距离和明暗非等距；独立的低频云团在山谷下方移动，移除容易形成横条的高频拉伸纹理。
- 色调以太阳高度和朝向混合白天冷色、晨昏暖色及夜色，支持红色夜间模式；这是美术配色，不是新增物理大气散射模型。没有新增纹理下载、联网、定位或设备权限。
- 这是装饰性虚拟地景，不是观测地点的真实山形、天气、地形模型或云量。它不参与实际地平遮挡、升落时间及可观测性计算；下方渐隐以保留纯净星图区域。

## 实现

- `LandscapeMist` 使用现有全屏绘制缓冲及 AltAz 反投影；投影类型变化时重建着色器，正常帧复用着色器与缓冲。在已有绘制循环的首次可用阶段准备资源与着色器，避免首次点击开关才全部准备。
- 固定山形只在 CPU 计算一次，存入 1024×5 的 R16F 周期高度查找表；基础随机场生成一次，存入 128×128 R8 缓存。原始像素约 26 KiB，非下载图片。每帧采样缓存、组合颜色及位移，不再让全屏每个像素重新运行多层随机哈希、取模和山形函数。保持原星图输出分辨率。
- CPU 整数取模连接整周随机采样点，查找表水平 Repeat；流雾噪声使用方向向量，避免全景图 UV 拼接边界。GLES 与高度采样器使用 highp，天底提前退出，避免极点方向不定造成条纹。
- 山脊边缘根据像素导数抗锯齿；必须在按可见方向提前退出之前计算导数，避免非一致控制流下导数未定义、产生上沿虚线。不靠大范围模糊掩盖轮廓。
- 使用原有更新与绘制循环，无额外帧定时器。只有可见或淡入淡出时增加动画时钟、绘制一遍程序化层；隐藏时不绘制雾山，不降低星图画质或分辨率。
- `LandscapeMgr.mistHorizonEnabled` 是统一可同步属性，写入 `landscape/mist_horizon_enabled`。ArkUI、CLI、快照恢复共享同一个动作，不维护第二套开关状态。
- 交互式导览临时关闭该装饰，以便自由检查目标，结束后随完整属性快照恢复。

## CLI 与回归

通过现有 `scripts/stellarium-cli.mjs`：

| 命令 | 参数 | 效果 |
| --- | --- | --- |
| `setActionChecked` | `actionShow_MistHorizon\|1` / `actionShow_MistHorizon\|0` | 打开/关闭偏好 |
| `setActionChecked` | `actionShow_Ground\|0` | 隐藏原地景，让备用雾山可见 |
| `getLandscapeInfo` | 无 | 返回 `mistHorizonEnabled`、`mistHorizonOpacity`、`mistHorizonDecorative` |
| `openUiPanel` + `setLayerTab` | `layers` + `4` | 打开地景设置 |

`mistHorizonEnabled` 表示雾山模式开关，与照片显示开关互斥；非地球或三维场景活跃时仍不显示。`mistHorizonOpacity` 表示渐变状态，不保证地平线位于当前视野或 GPU 已成功绘制。必须结合截图检查。着色器编译失败记录 `Mist horizon shader`。

- `node --test scripts/test-ohos-mist-horizon.mjs scripts/test-ohos-guide.mjs`：源结构、周期连续性、模式条件、动作及导览恢复契约检查。
- `node scripts/test-ohos-mist-horizon-pad.mjs <设备ID>`：通过 CLI 检查开关、照片互斥、边界转动、缩放、天底及 UI，并生成截图和 `/tmp/mist-pad-report.json`。测试结束恢复原生会话；首次安装先等待呈现 ready。
- 屏幕截图需人工检查，测试中的状态断言不能替代视觉判断；手机、多语言、全部投影及长期性能仍需专项回归。
- 当前标签提供中英及另八个语言键，说明提供中英及繁体地区键，其余沿用英文回退；不宣称全部语言已翻译。
