# 动态雾山地景

## 当前状态（2026-11-12）

当前生产采用原创固定观察点四层地形与多S纵深长脊混合网格、实时太阳照明及顺脊流动透显。hybrid几何已经接入，适配真实方位语义后本次聚焦测试21/21通过。构建及数学回归不代表外观或性能达标，实际截图、录像、设备计时与验收结论统一记录于 [真机验证记录](../testing/ATMOSPHERE-MIST-PAD-2026-11-12.md)。

## 行为与边界

- 不导入SkyGuide私有顶点、图像、材质、代码或公式。参考图提供低缓连续S形脊、双坡明暗的外观目标，录像提供近坡流动参考；不声称恢复原版shader。
- 装饰地景不代表真实地点、天气或地形，不改变升落、星等、实际地平遮挡和天文可观测性计算。观察点不随视图转向平移，山脊不随时间摆动。
- API为LandscapeMgr.mistHorizonEnabled，持久化键landscape/mist_horizon_enabled。照片/三维场景互斥、非地球抑制由Mgr负责，默认偏好与导览会话恢复保持不变。没有新增联网、权限或开关。
- 普通模式冷蓝灰低饱和；getFlagVividAtmosphere()增强暮光橙紫。保留实时太阳方向照明、距离空气透视、深夜归黑与夜视红色。

## 四层与多S纵深地形

- 四个连续地形层按方位分别调制脊线半径、高度和坡宽，以不同尺度构成近坡、近山和远山，层间高度贡献叠加于基面。最远层另有小幅18/31角频率高程变化，增加低矮轮廓起伏。其上组合六条不同起止半径、坡宽和高度的S形纵深长脊，形成实际曲面而非平涂轮廓；具体外观仍需真机确认。
- `layers()/layerProfile()`描述各层方位截面；`height(east,north)`直接计算高程。横截面两侧坡宽比例为1与0.60，采用圆滑脊顶、指数衰减与有限支撑，并向观察点渐消。旧Ridge、CrestSegment、bezier、crests和crestBearing兼容接口已删除；这里不沿用旧径向脊数量、峰数或路径参数。
- `LongCrest/longCrests()`定义纵深脊；每条用五个半径节点和角偏移作分段smoothstep插值。横向距离以r乘相对脊线的最短有符号角差近似，坡宽随半径增长，两侧比例0.64与1；独立起坡/退坡包络限制作用范围。脊高与四层高程经有界平滑最大值合并，零包络不改变基面。角差以atan2(sin(delta),cos(delta))展开，不依赖绝对角跨缝排序。
- 默认384方位×128径向环，内环半径3、外边界4200、固定眼高48（场景单位）；**49,153顶点、97,920三角形**。径向采样以四层脊线半径为锚点分段插值；每环对每条S脊在基准方位±20°内二分28次求采样半径与脊线方位的交点，再插值相邻S脊间的扇区方位。相同sector跨环不再表示固定方位，末脊接回首脊+2π。中心共用一点，方位接缝焊接，网格和噪声仅首次生成。
- 每点计算真实高程，顶点z存储高程减眼高；法线由网格径向/切向三维差分叉乘并归一化。检查径向顺序、每圈2π、非退化正向三角、单位上向法线及共享拓扑，不把具体层形或峰数作为测试契约。有限基础细分仍可能在放大时出现折线，投影细分不能补造未采到的地形。

### 顺脊flowCoordinate

- 每顶点追加一个float：`flowCoordinate=r/firstCrestRadius(angle)`，其中r是水平距离，angle取实际XY的atan2，第一层指四层地形中的最内层，不是新增纵深S脊的局部高点。中心为0，第一层脊线对应1；固定方位上随r递增，等值线随该层脊线形状延伸。它不依赖太阳、时间或旧高程加权前缘，因此不再使用k4/k8及其有效半径约束。
- `flowCoordinate(east,north)`用于基础顶点生成；GPU属性terrainFlow经surfaceFlow插值送入片元。实际细分midpoint取两端flow的算术平均，不在新位置重新求解析值，避免因细分改变原三角内的连续场。共享边反向和重复细分均检查插值一致性。
- 任意新候选必须保证第一脊线半径有限且为正，并复验flow有限性、径向单调、第一脊线=1及接缝。解析场的性质不等于任意投影下逐像素保证；实际网格、细分和覆盖回归仍须保留。

## 投影与CPU准备

- GPU使用getProjectShader()，齐次w为顶点距离，插值真实位置/法线。片元通过getUnProjectShader()拒绝无效射线及明显投影错误片元，私有深度为d/(d+128)。
- 视图签名包含模型视图、投影矩阵、pixelPerRad、viewport原点/尺寸/中心、翻转、widthStretch、设备像素比例及maskType。逐元素比较使用 `abs(current-prepared)≤1e-10*max(1,abs(current),abs(prepared))`；空、长度不同或非有限签名不复用。投影类型变化清缓存并重建shader。缓存命中不更新基准，微运动仍会相对上次实际准备累计触发重算，不量化角度或FOV。
- 首次每32三角计算AABB外接球及方向角锥，包含整块三角内部。移动时先剔除不相交块，惰性投影候选顶点，每个基础顶点本轮最多投影一次；工作数组复用容量。共3060块，块记录有效载荷146,880 bytes，vector容量可能更大。
- 角锥粗裁限Stereographic/Fisheye、FOV≤100°、视口居中、widthStretch≈1、有限cap且cap.d>.06；角锥增加3°保守余量。其他投影、宽视场、偏移/拉伸采用保守路径。
- 预缓存唯一基础边，每帧选候选顶点间的边；同一边只检查一次曲率中点，下一轮仅检查新分裂边/新对角线。保持0.65px曲率阈值、24px短边阈值、共享邻面分裂及8,192新增顶点预算，无需分裂的面保留原索引。
- 曲率检查仅计算与midpoint逐分量相同的float位置；临时Vertex法线为零，只传给读取position的投影回调，不进入结果网格。真正split仍计算原单位法线、线性插值flow并复用屏幕中点；不能将位置采样传给依赖法线的投影回调。
- 快路径要求角锥半角<90°且候选基础点均有效，最多3轮曲率，无重复接缝回调；中点投影无效时重走保守路径。保守路径最多9轮有效域/接缝处理。最终按三角bbox和2px余量删除屏外索引，总顶点≤57,345。
- 基础顶点一次上传，视图变化只写新增后缀及保留索引。索引buffer仅容量增长时分配，其余容量内write；仍可能GPU同步。唯一边缓存及活动边容量约2–4MiB，初始化排序/去重不包含在generate计时中。分裂哈希表仍可能分配，不能称为移动零分配。

### 桌面基准与诊断

`scripts/benchmark-mist-preparation.cpp`使用C++17/O2、2560×1600、两种投影、每组12帧预热＋72帧连续转向/俯仰。下表是四层地形接入前，在相同旧几何上比较128面块与32面块＋位置中点的六轮交替测量，各列为每轮均值的中位数；用于记录CPU优化依据，不代表当前hybrid几何耗时，也不将收益单独归因给法线省算。

| 投影 / FOV | 128面块 | 32面块＋位置中点 |
| --- | ---: | ---: |
| Stereographic 12° | 0.781ms | 0.368ms |
| Stereographic 60° | 1.223ms | 0.817ms |
| Stereographic 100° | 1.365ms | 1.007ms |
| Fisheye 12° | 1.361ms | 0.563ms |
| Fisheye 60° | 1.871ms | 1.275ms |
| Fisheye 100°（全量回退） | 4.455ms | 4.350ms |

- Stereographic 12–100°减少26–53%，Fisheye 12–75°减少26–59%；Fisheye100°在测试的保守角锥半球门外，差异仅2.4%，不视为确定收益。Stereographic60°平均候选面48,050→33,282，中点投影41,545→25,115。以上不含GPU工作，不能推断Pad帧率。
- 两版共960,000采样点中，725,079覆盖点，所有覆盖判定及有效深度值完全一致。原始六轮数据为 `/tmp/stellar-mist-block32-bench.json`。基准程序无参数仅计时；传输出路径时写60个视图的160×100 double深度样本，光栅对照不计入准备时间。
- 首次及每60次draw的临时 `Mist mesh profile` 记录签名差、投影门、prepare/上传耗时、候选面、边/中点检查、轮数及最终索引量。缓存命中时本帧工作计数为0，候选量/最终面数表示复用数据。
- `Mist mesh CPU draw-resolve-composite submission ms (not GPU time)` 记录准备之后的FBO/绘制/resolve/合成CPU提交及可能的驱动阻塞，首次可能含FBO创建；**不是GPU执行时间**。未用glFinish或同步GPU查询。

## 光照、alpha与俯仰过渡

- 日间groundTint为冷蓝灰(0.29,0.34,0.43)。坡面法线XY乘2后归一化，照明为0.50+0.50*max(N·L,0)。没有投射阴影、假描边或随噪声变化的固体表面颜色。
- 当前haze=.5时空气透视为1-exp(-d*(.00031+.00000009*d))。太阳高度约−17.19°以下颜色归零；夜视转红，不自发光。
- 片元以surfaceFlow作为前缘坐标。单位水平方位u生成edgePoint=3u，两次128² R8噪声采样分别位于edgePoint+wind和2.3edgePoint−.6wind，wind=(.09,−.065)*time。drift=.08*(billow−.5)+.025*(detail−.5)，范围±.0525；只推动顺脊前缘，不改变几何或法线。flow≤.001时跳过噪声采样，无raymarch或atan接缝。
- 令front=surfaceFlow、edge=front+drift：实体层 `solid=smoothstep(.64,1.08,edge)`；近侧薄波 `nearWave=.35*exp(-((edge-.53)/.18)^2)`；更近观察点的一条薄波使用 `outerEdge=front+.6*drift+.04*(detail-.5)`，`outerWave=.12*exp(-((outerEdge-.27)/.13)^2)`。两条波的峰值低于实体层，不再使用以世界距离表示的−55/−138中心。
- 合成采用 `ribbon=(1-(1-solid)*(1-nearWave)*(1-outerWave))*smoothstep(0,.12,surfaceFlow)`。薄波只增加实体前缘外侧的覆盖，不从实体中减去孔洞；中心渐消抑制波尾。front≥1.1325时，无论噪声如何solid都为1。第一脊线flow=1不等于该处在所有漂移状态下都已完全不透明，仍处于实体过渡范围。
- flow目标为 `(1-wideField)*(1-smoothstep(-.40,-.06,viewAltitude))`：窄视场从俯仰约−3.44°向下至−22.92°逐渐进入完整流动效果；独立0.42秒指数历史令抬头合拢柔和。它不等于1-portal。
- `lowerFade=mix(1,smoothstep(-1.32,-.30,worldAltitude),flow)`，`coverage=lowerFade*mix(1,ribbon,flow)`，最终 `alpha=opacity*portal*coverage`。抬头令flow趋零，收敛为完整地面；向下时依次出现远山、近山、近坡薄波和透明显星区域，这是待真机检验的层次目标。solid满覆盖只指ribbon，实际alpha仍受lowerFade、portal和总开关影响。
- portal目标为smoothstep(−1.42,−.48,viewAltitude)，对应约−81.4°至−27.5°，采用独立0.22秒历史；窄视场深下视最终全隐。首次绘制两种历史初始化至当前目标，后续dt限制0–.1秒。
- wideField=smoothstep(130,155,FOV)。传入shader的portal为历史portal向1混合，flow为历史flow乘(1-wideField)；155°以上实际portal=1、flow=0，lowerFade与ribbon均为1，总开关opacity仍有效。广视场朝天外围地面、朝地中心地面及夜间黑色覆盖保留为验收要求。

## 资源预算与限制

- 私有全分辨率RGBA8+DepthStencil FBO，支持时2×MSAA及resolve，失败退回无MSAA，分配失败不画。预乘alpha合成，不写共享星空深度，恢复GL状态及裁剪约束。
- 2560×1600颜色/深度及resolve约78MiB。基础顶点（含flow float）/索引约2.43MiB，另有工作网格、屏幕点、索引、唯一边及细分缓存；容量、驱动和哈希节点另占内存，不能以基础网格大小代表总量。
- 有限4200半径仍不能覆盖数学地平线，外圈高程与眼高决定剩余间隙；不沿用旧半径下的缺口角度。极端投影细分预算耗尽可能留细缝；窄FOV放大仍受有限基础网格限制。
- 仅最近装饰曲面自遮挡，透明处不累积后方多层地形；没有太阳投射阴影、真实平移、多次散射或顶点波浪。透明显星是原创美术表现。
- 首次同步创建、移动CPU准备/GPU上传、宽视场全量处理与FBO内存仍有成本。山脊疏密、双坡可读性、流动是否自然及实际帧时均需真机评估，不以测试通过代替验收。

- 真机检查应覆盖固定视图及转向返回、75/30/12°脊线和内部遮挡、静止3–8秒流动、抬头/下视往返、宽视场完整地面与夜间黑盘。结果及后续缺陷以 [真机验证记录](../testing/ATMOSPHERE-MIST-PAD-2026-11-12.md) 为准。
