# 通知内容扩展设计（2026-10-14）

> **状态：** 设计稿（未实施）
> **关联文档：** `specs/NOTIFICATION-EVENT-CATALOG-DESIGN.md`（事件类型目录与文案模板，本文档消费其类型 ID）、`research/NOTIFICATION-AND-FORM-ROADMAP.md`（通知能力边界）、`docs/harmonyos/AGC-CAPABILITY-APPLICATION-PLAN.md` 相关章节（实况窗/优先通知权益申请）

---

## 1. 目标

事件类型目录解决了"通知什么"；本文档解决"通知长什么样、点了去哪里"——为每类天文通知定义内容结构、视觉层级和点击路由，重点覆盖卫星过境这类强时效通知的内容扩展。所有设计约束在现有离线通知能力（Notification Kit 本地通知 + `reminderAgentManager` 代理提醒）之内，实况窗内容形态作为权益获批后的增强项，不作为前置依赖。

## 2. 通知内容分层结构

每条通知的内容由统一字段结构生成，避免各类型各写一套：

| 字段 | 作用 | 示例（卫星过境） |
| --- | --- | --- |
| `title` | 类型化标题 | 「国际空间站过境」 |
| `body` | 主结论句（模板生成，见目录文档第 3 节） | 「今晚 19:42–19:48 西南→东北，最高 62°，亮度 -3.8 等」 |
| `detailLines` | 结构化事实行（最多 3 行，多行文本通知） | 升起 19:42 方位 233° / 最高点 19:45 高度 62° / 落下 19:48 方位 45° |
| `progress` | 可选进度语义（实况窗形态用） | 过境进行中（30%） |
| `category` | 类型 ID（目录文档） | `satellite-pass` |
| `route` | 点击路由参数 | 面板 + 天体 + 模拟时间 |

约束：`body` 一句话说清"何时何地看什么"；数字事实进 `detailLines` 不进长句；标题不堆感叹号；通知内不出现观测经纬度原文（用地点名称）。

## 3. 各类型内容规格

### 3.1 卫星过境（重点扩展）

卫星过境是全目录时效性最强的类型，内容扩展最多：

- **提前提醒**（过境前 10 分钟）：标题「{卫星名}过境即将开始」；`detailLines` 给开始时刻、起始方位、最高点时刻/高度；点击直达卫星面板并预载该卫星。
- **过程提示**（仅实况窗形态）：进行中状态显示实时进度与当前方位；权益未获批时**不发**过程提示，不过程频发普通通知（普通通知最多发"开始"一条）。
- **数据可信度**：TLE 过期时提醒内容追加"轨道数据截至 {日期}，时刻可能偏差"；过期超阈值直接停发并按目录文档第 4.5 节标示原因。
- **类别细分**：`iss`（国际空间站）、`bright`（明亮过境）、普通过境三种标题模板；ISS 使用专有文案，普通卫星使用通用模板，不用 ISS 话术。

### 3.2 日月食

- `detailLines`：食类（全/偏）、初亏/食甚/复圆时刻、本地可见性结论（"本地区可见偏食，最大食分 0.86"）。
- 点击直达天文计算食页面；观测点不可见时仍可点击查看详情，但 `body` 必须明示"本地区不可见"。

### 3.3 流星雨

- `detailLines`：峰值时刻、辐射点星座与后半夜可见性、月相干扰结论（"满月严重干扰" / "无月光干扰"）。
- 点击直达流星雨面板。

### 3.4 月相与超级月亮

- `detailLines`：月出/月落时刻、照明比例；超级月亮附"今年最大满月/第 N 大"结论。
- 点击直达月相面板。

### 3.5 冲日/大距/合相

- `detailLines`：天体名、事件时刻、观测窗口（"日落后西方低空约 40 分钟"）；大距标注东/西。
- 点击直达对应天体详情或天文计算面板。

### 3.6 分至点与节气

- 复用已实现的节气提醒内容；分至点通知 `body` 附半球语义（目录文档半球变体）；点击达年历页。

## 4. 通知形态与系统映射

| 形态 | 映射 | 适用 | 状态 |
| --- | --- | --- | --- |
| 基础文本通知 | Notification Kit 文本类型 | 默认形态 | 可用 |
| 多行文本 | 多行文本类型 | `detailLines` ≥ 2 的类型 | 可用 |
| 图片通知 | 图片类型（本地生成的星图/月相图） | 暂不启用；本地渲染图片的生成成本与体积先评估 | 预留 |
| 实况窗 | AGC 实况窗权益（需申请+Profile） | 卫星过境过程提示、食甚倒计时 | 未获批 |
| 代理提醒 | `reminderAgentManager` | 全部定触提醒 | 已接代码，权益待批 |

- 实况窗**未获批前**，第 3.1 的"过程提示"不实现，不得用连续普通通知模拟实况窗。
- 图片通知若启用，图片必须本地生成（不内置大图资源），缓存过期清理，不进卡片快照。

## 5. 通知行为与分组

- **通知类别（slot）**：按目录文档八大类建通知类别，用户可按类别在系统设置静音；应用内订阅开关与系统类别一一对应。
- **折叠与去重**：同类型同目标 24 小时内只保留最新一条（更新原通知而非叠加）；多颗卫星同晚过境合并为一条汇总（"今晚 3 次明亮过境"），点开展开列表。
- **免打扰时段**：规则级 `quietHours`（目录文档契约字段已有）在注册提醒时避开；无法避开的天象（如食甚）允许"重要提醒"标记，但必须用户在类型订阅时单独勾选。
- **点击路由**：统一 WantAgent 回 `QAbility`，携带 `route`（面板 + 天体 + 模拟时间）；通知点击只在应用前台直达面板、后台先拉起应用；路由失败回主界面并记日志，不白屏。
- **清理**：过期未触达的通知由下次快照刷新时静默取消；用户关闭某类订阅时同步取消该类已注册提醒。

## 6. 隐私与合规

- 通知内容不包含经纬度数值、设备标识或任何外发数据；地点只用用户可见的地点名称。
- 不接入 Push；内容全部本地计算、本地生成、本地发布。
- 代理提醒内容规范持续符合华为"代理提醒"能力要求（非营销、非广告）；实况窗申请材料以卫星过境场景（明确开始/结束时间）为主候选。
