# 触觉反馈与缩放转场动效设计（2026-10-14）

> **状态：** 设计稿（未实施）
> **关联文档：** `research/ARKTS-PAGES-REFACTOR-PLAN.md`（页面路由与面板结构）、`specs/STARTUP-MOTION-DESIGN.md`（既有动效基调）

---

## 1. 触觉反馈系统

### 1.1 目标

为关键交互提供统一、克制、可关闭的触觉反馈层：用户在选星、切换面板、确认操作时获得"实体感"反馈，但振动不成为噪音——低频操作强反馈、高频操作弱反馈或无反馈。

### 1.2 架构：统一 HapticsService

新建 ArkTS 层 `HapticsService`（单例，随宿主初始化），所有触觉反馈经它发出，禁止组件直接调用振动 API：

```text
组件/控制器 → HapticsService.trigger(反馈语义)
                  │ 读全局开关 + 场景判定
                  ▼
              @ohos.vibrator（@kit.SensorServiceKit）
```

- **能力探测**：初始化时查询设备振动能力与支持的振动效果；不支持时所有 trigger 静默返回。
- **全局开关**：设置页新增"触觉反馈"开关，默认开，持久化到本地偏好；关闭后 service 内部短路，不动调用方。
- **强度分档**：只定义三档语义——`light`（轻点/选择）、`medium`（确认/模式切换）、`heavy`（显要事件，如食甚提醒弹窗），映射到系统预设振动效果；不使用自定义波形（省电且跟随系统强度设置）。

### 1.3 触发点清单（首批）

| 场景 | 档位 | 说明 |
| --- | --- | --- |
| 选中天体（点击选星成功） | light | 高频操作，轻反馈即可 |
| 搜索结果项点按 | light | — |
| 面板打开/关闭 | light | 面板切换已有多频操作，只用轻档 |
| 书签保存 / 复制成功 | medium | 确认类 |
| 图层开关（银河/星座线等） | light | — |
| 时间跳转到位（如跳到食甚） | medium | 显著状态变化 |
| 天象提醒到期弹窗 | heavy | 低频显要事件 |
| 观测目标进入视场中心（对准提示） | medium | 望远镜/寻星场景 |

**禁止触发**：拖动星图、连续缩放、滑块调节、每次帧刷新——这些高频路径触发振动会造成手部不适与电量消耗。

### 1.4 验证与边界

- 真机验证档位手感（模拟器无振动）；每档触发延迟 < 50 ms 感知即时。
- 振动不进卡片、通知扩展与后台；应用后台时 service 拒绝触发。
- 不新增权限以外的任何采集；振动设置不参与任何同步/上报。

## 2. 缩放转场动效

### 2.1 目标

列表项 → 详情页采用"放大承接"转场：用户点按列表里的天体卡片/天象条目，卡片作为共享元素放大、展开为详情页；返回时反向收缩回列表原位。让用户始终知道自己"从哪来、回哪去"，替代生硬的全屏推入。

### 2.2 适用场景（首批）

| 起点卡片 | 终点详情 |
| --- | --- |
| 今晚天象条目 | 对应天象详情面板 |
| 行星卡片 / 桌面卡片对应应用内页 | 行星详情 |
| 搜索结果项 | 天体详情 |
| 年历月相日 | 当日天象详情 |

### 2.3 技术实现

- **共享元素**：起点卡片根节点与终点详情头部节点标注 ArkUI 共享元素转场标识（`geometryTransition`，同名配对），转场期间系统在两个页面间做几何插值（位置/尺寸/圆角）。
- **转场裁剪**：详情页内容在承接完成前用裁剪容器限制可视区域，图片/纹理延展只发生在容器内，避免内容溢出到圆角外（转场裁剪修饰器思路）。
- **曲线与时长**：承接动画约 300～350 ms，使用系统标准缓动曲线；返回转场稍快（约 250 ms）。时长与曲线全局常量化，不逐页魔改。
- **降级**：开启系统"减少动效"辅助功能设置时退化为普通淡入淡出；转场中路由数据未就绪时先展示骨架承接壳，不阻塞点按响应。
- **与既有动效协同**：遵循 `STARTUP-MOTION-DESIGN.md` 的既有动效基调；面板内小型浮层（工具条、快捷操作）不用承接转场，保持现有位移动画，避免全局过度动效。

### 2.4 工程约束

- 转场只发生在 ArkUI 层，不触碰 Qt 星图渲染与命令桥；星图视图本身不参与共享元素（GL 纹理无法安全插值），涉及星图的跳转保持现有面板切换动效。
- 每个承接对（起点/终点）登记到本文档 2.2 清单后再实现，禁止随手给任意组件加共享元素标识导致转场配对泄漏。
- 性能验收：真机中端机型转场帧率不掉破 55 fps；列表滚动中快速点按不产生转场错位。

## 3. 实施顺序

1. **第一批**：HapticsService 骨架 + 全局开关 + 选星/面板开关轻反馈；缩放转场先落"今晚天象 → 详情"一对。
2. **第二批**：反馈档位补全与提醒 heavy 档；搜索结果与行星详情承接对。
3. **第三批**：减少动效降级、低端机性能验收与手感调优。

每批完成在 CHANGELOG 记录真机验证结果；振动档位与转场参数的真机手感应由用户确认后再固化默认值。
