## 一、外部开源图形学仓库评估（`AshenOneArt` / `NVIDIA PRL` / `lzq1206`）

### 1. `AshenOneArt` GitHub 主页评估（10 个公开仓库）

| 仓库 | 协议 / 技术栈 | 与星象仪的契合度 | 建议采纳内容 | 不建议照搬内容 |
|---|---|---|---|---|
| **`HPVolumeCloud`** | MIT 修改 / HLSL（Unity HDRP） | **高（直接助力 Phase 3 火箭云渲染）** | **`phi_fwd` 物理漫射场（各向同性多重散射加性项）**：解决传统单次散射（Henyey–Greenstein）在厚云/浓密固体火箭氧化铝烟带内部指数变黑的问题，让厚烟带与高空水母云呈现真实饱和通透发光。 | HDRP 完整体积云 RenderGraph 管线（面向 PC DX11/DX12，手机端过重）。 |
| **`HPWater`** | MPL-2.0 / HLSL（Unity HDRP） | **中（仅借鉴体积光优化范式）** | 1. **低分辨率体积积分 + IGN（Interleaved Gradient Noise）交错梯度噪声**去条带；<br>2. **联合双边上采样（Joint Bilateral Upsampling）**：保留边缘清晰度、防止颜色渗漏（同样适用于 AR 地景遮罩边缘羽化与体积火箭云合成）。 | PC 级光追折射、Compute Shader 焦散光子追踪、完整波方程流体仿真。 |
| **`3DTextureExportTools`** / **`hanpi-toolbox`** | C# / HTML | **中（离线资产工具）** | 离线生成轻量 **64³ 3D Worley/Perlin 噪声纹理**，供 OpenGL ES 片元着色器实时驱动固体火箭烟带高空风切变湍流与水母云丝状细节。 | Unity Editor 运行时依赖。 |
| **`Unity-SWE`** & **NVIDIA PRL 浅水方程论文**（*Dispersive Surface Waves*） | 流体仿真研究 | **低（偏离主线）** | 仅作为图形学技术储备参考。 | 不建议引入星象仪：浅水方程+Airy 色散波+卡门涡街面向 3D 游戏水体交互，移动端 GPU 功耗与复杂度过高；未来海上发射场海面仅需轻量法线波纹+星空倒影即可。 |

## 二、火箭发射弹道仿真与火箭云全周期路线（Phase 1 → Phase 5）

### 已落地基线（Phase 1 + Phase 2，2026-11-27 平板实机验收通过）
- **C++ 物理与火箭云核心（`RocketLaunchMgr`）**：WGS-84 自转地球 + $J_2$ + US76 大气 3-DOF RK4 上升段积分（7–11 ms）、助推/整流罩/一级独立再入落点与 120 点蒙特卡洛散布、ICAO NOTAM（Q 行圆 + E 行多边形）解析与射向/倾转角自动反演、16 发射场 + 22 款覆盖 6 类推进剂的箭型库 + 6 经典复盘、地影切点高度 $h_{\text{eff}}$ 与 0–100 火箭云观赏评分。
- **天象日历与可视化 UI**：天象日历专属仿真入口、±60 分钟发令时刻微调滑块、Az–Alt 观测天空轨迹图（时间色带 + 火箭云高亮段 + Stellarium 地景地平线遮挡）、**花瓣地图 3D 卫星地球 + 晨昏线 + `toScreenLocation(latLng, alt)` 凌空 3D 上升/回落弧 + NOTAM 红区与散布云**。

### Phase 3：Stellarium 星图内 3D 实时弹道弧与物理火箭云渲染（近期）
1. **OpenGL ES 3D 实景轨迹与动态火箭**：在真实星图天球上渲染分阶段彩色上升弧、飞行中的发动机尾焰高光与分级事件悬浮标签。
2. **融合 `HPVolumeCloud` / `HPWater` 思路的 6 类推进剂实时火箭云**：
   - **固体推进剂**：连续体积烟团带 + 分层高空风切变 S 形扭曲漂移 + **`phi_fwd` 简化多重散射**（避免烟带核心发灰发黑）+ 按 $h_{\text{eff}}$ 实时着色（地影暗灰 → 0–25 km 金红橘粉 → >25 km 耀眼白金）。
   - **液氧煤油 / 液氧甲烷 / 液氢液氧 / 常规液体**：随气压 $P(H)^{-1/2}$ 实时张开的半透明欠膨胀“太空水母”光罩 + IGN 抖动去条带 + 级间分离/二次点火瞬态扩散冲击环。
   - **固液混合（如长征六号改）**：助推分离前发射持久固体烟带，助推分离后固体烟带继续飘散，芯级/二级高空无缝接力展开青白水母。
3. **沉浸式预演控制条与摄影构图**：`T+0s ~ T+900s` 进度拖动、`1x/5x/20x` 倍速、发射时间偏移微调、全画幅/APS-C/手机常用焦段取景框（14/24/35/50/85/200 mm）与“追踪火箭 / 固定机位”切换。

### Phase 4：公开航天排期与 NOTAM 云端自动同步（中期）
- 在现有自有境内静态镜像 `https://skyinstrument.cn` 部署定时抓取脚本（每 30–60 分钟静默更新静态 JSON + SHA-256 校验，端侧**零隐私上传**）：
  - 排期源：Launch Library 2 等公开航天排期；
  - 航警源：参考 `notam-whisper` 思路合并公开 NOTAM 与海事航警（NGA MSI / 中国海事局），用“时间窗重叠 + 落区矩形长轴回指发射场 + 多落区共线走廊”规则自动配对到具体发射任务，自动写入天象日历并支持发射前本地提醒。

### Phase 5：3D 火箭实机模型 + 3D 发射场拟真场景（远期重磅拟真升级）
为大幅提升科普观赏性与“现场直击”沉浸感，远期分步引入**可分离 3D 火箭模型资产库**与**真实发射场 3D 场景库**：

1. **每款运载火箭的分级 3D 模型库（按需分包下载，不膨胀主包体）**
   - **模块化分级拆分规范**（glTF 2.0 / GLB，Draco/KTX2 轻量化，单箭目标 < 1.5–3 MB）：
     - 每枚火箭按独立子网格拆分：`booster_0..N`（助推器）、`stage_1`（芯一级）、`fairing_L / fairing_R`（左右整流罩）、`stage_2`、`stage_3`、`payload`（载荷/空间站/飞船）。
     - 同步标注各发动机喷口挂点（Nozzle Anchor），精准绑定尾焰火光与火箭云发射源。
   - **三大复用场景**：
     - **火箭图鉴/详情 360° 检视**：复用星象仪现有 `ObjectDetailModel` 3D 模型渲染器，查看各箭型尺寸对比、推进剂结构与分级解剖爆炸图；
     - **发射场近景起飞动画**：点火瞬间触发导流槽白烟/水雾、摆杆脱开、起飞离架与分级分离动画（助推器翻滚脱离、整流罩双瓣抛离、热分离火焰）；
     - **3D 轨道/星图追踪近景视角**：开启“跟随箭体”镜头时，直接以真实 3D 火箭本体在星海与地球弧线前飞行（类似高拟真航天直播 3D CG 视角）。
   - **分批建模优先级**：
     - Batch 1（中国主力）：长征六号改、长征五号、长征七号、长征二号F（含逃逸塔）、快舟一号甲、朱雀二号改进型；
     - Batch 2（中国商业与高频）：长征八号、长征十二号、长征三号乙、谷神星一号、力箭一号、引力一号、捷龙三号；
     - Batch 3（国际标杆）：Falcon 9（含栅格舵与着陆腿）、Starship / Super Heavy、Ariane 6、H3。

2. **真实发射场 3D 场景 / 实景地景库（按需扩展包）**
   - 结合星象仪现有的 `Landscape` / `Scenery3d` 能力，为高频发射场打造**高精度工位全景地景 + 轻量 3D 发射塔架模型**：
     - **文昌航天发射场（LC-101 / LC-201）& 海南商发**：海岸椰林、发射塔架、轻量海面波纹与星空/火光水面反射（用轻量法线贴图+平面/屏幕空间倒影实现，不引入重型浅水流体计算）；
     - **酒泉卫星发射中心（921 载人塔架 / 商业工位）**：戈壁滩与垂直总装厂房地平线；
     - **太原卫星发射中心 & 西昌卫星发射中心**：真实山谷地形遮挡轮廓（与真实山脊遮挡完全一致）；
     - **东方航天港（海阳海上发射船）**：海上发射驳船甲板视角，360° 无遮挡海平线。
   - 支持**“发射场观礼视角”一键瞬移**：把观测位置切换到发射场附近经典机位（如文昌淇水湾/龙楼镇、海阳海滩），体验身临其境看火箭从塔架拔地而起的震撼视角。

## 三、AR 实景星空融合远期演进路线（AR v1 → v5）

### 当前已落地基线（AR v1，2026-11 现状）
- 已打通全机型可用的 **Camera Kit → `OH_NativeImage` → OpenGL 外部纹理 GPU 单通融合**（`ArCameraService.ets`），仅在用户主动开启 AR 时按需申请相机权限，退后台立即释放；
- `SensorController.ets` 已落地 **120Hz 采样 + 9ms 轻滤波 + 36ms 角速度前瞻预测**，显著降低转头时星图滞后拖影。

### 远期五阶段演进路线

| 阶段 | 核心目标 | 关键技术方案 | 解决的真实痛点 |
|---|---|---|---|
| **AR v2：光学 FOV 标定与零偏校准** | 让星图星点与相机画面中的真实亮星/日月毫秒级、亚度级严格重合 | 1. 读取相机真实物理内参（焦距/传感器尺寸/畸变系数），自动同步星图 FOV 与宽高比，支持 0.5x 超广角 / 1x 主摄 / 2x–3x 长焦无缝联动；<br>2. **一键星点/日月锚定微调**：允许用户单指微调将星图中的太阳/月亮/金星/木星/亮星拖到实景画面重合位置，持久化方位零偏补偿；<br>3. 进阶探索端侧**单帧极速亮星识别（Plate Solving）**自动归零磁力计偏航误差。 | 彻底解决城市钢筋建筑旁磁力计 5°–15° 偏航误差、以及不同手机镜头 FOV 与星图不匹配导致“星对不准”的最大痛点。 |
| **AR v3：真实地景遮挡抠除（树枝 / 楼宇 / 山体）** | 星星、银河与星座只出现在真实天空区域，被树木和建筑挡住的部分自然隐藏 | 1. **多信号融合遮罩**：旗舰机型优先接入华为 **AR Engine 深度图 + 竖直平面 + 环境 Mesh**；无 AR Engine 深度机型回退端侧轻量天空/地景分割（需严控离线模型体积 < 5 MB）或夜间亮度/梯度地平线检测；<br>2. **边缘防闪烁管线**：借鉴 `HPWater` 的 **时域平滑 + 联合双边滤波上采样（Joint Bilateral Upsampling）**，避免树叶、电线杆边缘星星抖动闪烁；<br>3. **保守安全回退**：强逆光/极暗噪点导致置信度低时，宁可退回纯净星空半透明叠加并温和提示，绝不误抠真实星空。 | 从“半透明叠图”进化为“真·空间融合 AR”，夜晚在城市阳台或树林里观星沉浸感质变。 |
| **AR v4：AR 实景蹲守火箭云 & 空间站过境（独家杀手锏）** | 把 AR 相机与天象日历、火箭弹道仿真、卫星过境打通 | 1. **AR 追火箭模式**：发射前举起手机/平板对准天空，实时在真实地景上空绘制**火箭上升预测虚线、跃出地影高度线、助推/一二级分离点、预计火箭云展开区域与实时倒计时**，帮摄影师直接用手机找准三脚架机位、避开楼宇和树冠遮挡！<br>2. **AR 追中国空间站/ISS 过境**：在实景天空叠加过境轨迹弧、进入/退出地影点与实时倒计时指向箭头；<br>3. 同步叠加所选相机焦段取景框（14–200 mm），直接所见即所得定构图。 | 将 AR 从“认星座玩具”升级为天文与航天摄影师**外出蹲守火箭云、空间站凌日/过境的刚需实景寻星工具**。 |
| **AR v5：6-DoF 空间锚点、弱光夜视与门户体验** | 面向支持 AR Engine 6-DoF 的旗舰手机/平板/未来 XR 设备 | 1. **VIO 视觉惯性融合**：结合 AR Engine 运动跟踪消除长时间手持观星的陀螺仪累积漂移；<br>2. **夜间弱光相机策略**：进入夜间 AR 时自动锁定适度 ISO/曝光上限并关闭自动对焦抽风（锁定无穷远焦点），保留地景剪影而不噪点满屏；<br>3. **地景渐隐门户（Portal）**：将已有 `overlay / portal / depth / sky-only` 四模式与真实相机打通，支持“撕开城市楼宇/雾霾直见深空银河”的震撼展示；<br>4. **严格隐私红线**：所有相机帧、深度图与位姿仅在端侧 GPU/内存实时消费，**绝不上传网络、不写日志、不静默后台采集**。 | 充分释放鸿蒙旗舰设备硬件潜力，并提前为折叠屏支架态与未来鸿蒙空间计算设备做好架构铺垫。 |
