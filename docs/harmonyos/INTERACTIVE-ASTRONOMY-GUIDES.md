# 交互式天文导览

日期：2026-09-08。首轮重构，尚不等同于全部上游脚本已经转换。

## 用户体验

统一入口为“更多功能 → 脚本与自动化”。上方是触屏原生导览，下方保留原版脚本兼容入口和作者/许可资料。

- 首批两条离线路线：太阳系邻居（月球、金星、火星、木星、土星），走进深空（M31、M42、M45）。讲解为本项目新编，不伪装成原脚本作者文字。
- 默认手动逐站前进，不强制倒计时；支持上一站、下一站、近看、远看、暂停、继续及可选自动前进。
- 自由观察明确把星图手势交给用户，暂停站点推进；“返回导览”重新选中该站目标并恢复预设视野。普通观测态不让误触拖动打断镜头。
- 时间暂时静止，隐藏大气与地面，让地平线下的目标也能查看；界面明确说明这是模拟探索，不冒充现实可见性建议。
- 手机底部居中、宽屏靠侧，共用一个卡片。只有标题区可拖动，讲解和辅助控制在有界 Scroll 内完整滚动；关闭始终在固定标题栏，上一站/暂停/下一站固定在底栏。采用共享圆角、44/48vp 控件和缓入缓出过渡，不缩小字体挤入 224vp。
- 这里不播放合成语音；“自动前进”不能标成自动讲解。图片是否就绪仍以原有资源加载链为准，不把命令成功说成贴图解码成功。

## 架构

`AstronomyGuide.ts` 将离线内容清单、步骤和播放器分开。`GuidePlayer` 不依赖 ArkUI，通过注入的异步命令执行器调用现有天文核心；ArkUI 和 CLI 调用同一播放器。

状态：`idle → preparing → observing ↔ paused/exploring → restoring → idle`，失败保留 `error`、重试和退出入口。只有 observing 且 automatic 时消耗倒计时。后台暂停，回到前台不自动继续；页面销毁尝试恢复。

命令逐条确认后才进入观察态。正在切站时拒绝重入，退出等在途命令结束后恢复，不让旧回调继续切换目标。恢复失败保留活动会话和错误，不伪报退出成功。原生和导览互斥，不同时控制相机。

ArkUI 按钮的动作身份切换（暂停/继续、自动/手动、最后一站完成）使用显式条件分支，启用状态直接读取播放器状态。真机曾复现给 Builder 传动态字符串/布尔值后保留旧参数，导致状态已经暂停而按钮仍执行暂停；不要重新改回这种写法。回归必须实际触摸暂停再触摸继续，不能只验证 CLI 状态。

`StelScriptMgr::beginGuidedSession/endGuidedSession` 复用原脚本完整会话快照（时间/速率、观测地点、时区、投影、视角/上方向、FOV、跟踪、可同步属性、选择）。不是使用缺少速率和完整恢复的 `getSessionState/applySessionState` 代替。导览无需阻塞脚本事件循环，恢复采用即时版本，不调度旧脚本的 0/120ms 二次恢复，以免污染下一会话。

此快照范围不包括任意脚本写入的文件、外设物理动作和全部不可同步插件内部数据；不宣称所有可能副作用可逆。本轮导览仅执行固定白名单式步骤，不调用外设、文件写入、权限请求或网络。

## CLI 契约

| 命令 | 参数 | 反馈 |
| --- | --- | --- |
| `startGuide` | `solar-neighbours` / `deep-sky-discovery` | 受理后通过状态查询核对执行结果 |
| `guideAction` | `previous`, `next`, `pause`, `resume`, `explore`, `return`, `closer`, `wider`, `center`, `auto-on`, `auto-off`, `retry`, `stop` | 不支持的动作/错误状态返回实际失败 |
| `getGuideState` | 空 | `state`、`lastRequestId`、`result`、导览清单；未初始化为 idle |
| `beginGuidedSession` / `endGuidedSession` | 空 | 核心快照接口，供播放器使用，不用于代替 UI 导览命令 |

CLI 的 `accepted` 只表示 UI 请求送达。最终检查对应 `lastRequestId` 和 `result.ok`，以及 `state.phase`，不能以一次受理响应证明已定位目标或已恢复。

## 上游兼容与后续扩展

保留 `.ssc/.inc` 执行器、脚本导入及原署名、许可。Qt 6 旧脚本不支持任意暂停，不能简单把模拟时间设成零冒充暂停脚本。虚拟键只属于兼容入口，新导览不发送虚拟 N/B 等按键，也不从字幕关键词推断控制。

后续以版本化 manifest 扩展：每站目标、讲解多语言键、可选交互动作、完成条件、所需资源、署名许可。先将上游常用导览人工核对为声明式流程，再考虑用户导入；导入需要 schema/大小/路径/动作白名单校验，不能直接 eval 未知代码。不会承诺新增上游脚本无需适配便可自动变成原生互动。

天球绑定标签继续由核心绘制；新导览讲解由 ArkUI 原生 Text/Scroll 呈现，统一生命周期。旧脚本屏幕字幕迁移及语义互动声明是下一阶段，不把历史 `SCRIPT-DESIGN.md` 的“不建立 ArkUI 讲解层”继续作为新导览约束。

首轮新讲解为简体中文和英文，其他语言沿用 I18n 回退；部分标题有繁体。未宣称新增文案已完成 43 语言本地化。下一阶段按项目翻译流程完善，不硬编码天体译名。
