# 卫星导入、在线更新与面板验收（2026-11-12）

## 规则

- 以 NORAD 编号识别同一卫星，比较 TLE 轨道历元；较旧或相同历元不覆盖现有轨道。多来源的“允许新增”标志独立合并，不再决定轨道覆盖顺序。
- 用户明确导入文件时允许新增卫星，不受在线自动新增开关影响。已有 userDefined 条目和此次来源未包含的卫星仍保留。
- 一次多文件导入有任一无效文件或不可读路径，整个批次失败；先验证，后用 QSaveFile 原子保存，成功后才变更运行中目录。
- 在线更新逐来源验证。坏来源不合并，正常来源继续；部分失败返回 CompletePartial（5），全部失败返回错误，不伪装为更新成功。
- 更新中拒绝另一次导入、刷新、来源修改或默认来源恢复，返回 satellite_update_busy。
- 接受 2LE/3LE、BOM、CRLF、有效 CSV；拒绝错误校验和、编号不匹配、不完整行、非法历元/角度、NaN/Infinity、HTML/错误文本。文件上限 32 MiB、行长上限 4096；ZIP 解压体积受限。
- 网络请求有传输 30 秒和总时限 60 秒；自动更新尝试间隔至少 30 分钟，重试期限落盘并跨进程恢复，成功后仍按原定更新周期运行。手动刷新可立即重试。
- 这些是格式、轨道字段、事务和冲突保护，并不是来源真实性认证。v1 镜像尚未接入签名清单；格式正确但伪造的科学数据不能靠 TLE 校验和鉴别。

## 界面

卫星主页面保留数量、更新状态、手动刷新、自动更新、分组和搜索。高级设置分为文件导入、来源、显示、倒计时和数据详情。文件选择与路径导入分开；来源开关明确只控制是否新增卫星。CLI 增加 setSatellitePanelSection，并验证允许的页面名称。

## 自动更新与详情补充验收

- 根因：`loadSettings()` 的 `Q_OS_OHOS` 分支无条件覆盖已保存的自动更新选择，且 `init()` 另有 `#ifndef Q_OS_OHOS` 阻止创建更新定时器。联网版已同时移除这两处限制，初次安装默认保持关闭。
- 开关、间隔和来源设置同步落盘；下一次自动尝试期限也持久保存。更新过程不清空原目录。自动模式不显示全局加载条，手动刷新保留进度反馈。
- 每 13 秒只判断本地到期条件，默认 72 小时更新一次；完全失败至少间隔 30 分钟再试，且仍尊重上次成功后的正常周期。用户结束进程后不会继续下载，重新打开时恢复设置和调度。
- 详情现在显示最近检查/导入结果及时间、轨道最近实际变更时间；内置快照单独标明。删除把随包健康清单当成运行中目录健康的展示，桥接口返回实际用户目录路径。
- 打开卫星面板期间轻量回读本地状态，完成后刷新目录；关闭后停止页面轮询。回读不会覆盖用户正在编辑的更新间隔。
- 新增 `scripts/test-satellite-persistence-pad.py`：强制结束/重启开关保存、到期自动请求、无变化检查记录、详情同步、损坏数据拒绝及重启后冷却。回环测试不改生产镜像，结束恢复设备正式配置并保留开启状态。
- MatePad Mini 专项 **16/16** 断言通过，证据 `/tmp/satellite-persistence-pad/checks.json` 和 `panel.json`。首次覆盖安装后核心尚未就绪，最初读请求超时，未进行注入；就绪后完整回归通过，脚本已补启动就绪重试。
- 最终包再次覆盖安装后，正式来源刷新返回部分成功（5），18,168 颗卫星，自动更新仍开启。详情回读显示检查时间 `2026-11-12T12:16:51.743Z`、实际轨道变更时间 `2026-11-12T11:53:19Z`，两者正确区分；运行目录路径返回沙箱文件而非源码路径。详情截图 `/tmp/satellite-persistence-details.jpeg` 无裁切，HDC 转发列表为空。

## 服务器联调事实与边界

46 个已配置来源均能下载：44 个自建 HTTPS CSV 镜像、AMSAT 文本和 McCants ZIP。gpz.csv 与 gpz-plus.csv 返回 HTTP 200，但正文是上游 Invalid query 错误文本；客户端实际解析拒绝。active.csv 最近抓取失败（403），服务器保留了历史版本；HTTP 200 不代表轨道新鲜。

服务器仍运行旧版 /opt/tle-mirror/fetch-mirror.mjs。仓库 deploy/tle-mirror 内的加固抓取器尚未部署。只读核对的实际用户为 skyops，脚本和目录归 root，systemd 抓取服务仍以 root 运行；本轮未绕过权限或改生产运行身份。服务端后续应受控部署新校验器、隔离历史错误文件、公布 stale/unavailable 状态并改用专用低权限抓取身份。客户端的拒收不等于服务端已修复。
