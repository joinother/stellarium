## P1 - 高优先级

### 1. 边缘区域选星被 UI 死区吞掉

- **状态：** 已修复（isUiPoint() 收窄到按钮区域，工具栏容器改为 Transparent）
- **现象：** 屏幕左边/上/下边缘区域的点击被当作 UI 区域吞掉，不会触发选星
- **根因：** `isUiPoint()` 和 `expandedShell` 的触摸路由中，整条工具栏区域（包括按钮旁边的空白）都被 `HitTestMode.Block` 拦截
- **修复方向：**
  1. 让工具栏容器改为 `HitTestMode.Transparent`，只在按钮上设 `Block`
  2. 收窄 `isUiPoint()` 的判断范围到仅覆盖真实按钮
  3. 参考 WorkBuddy 在 2026-07-20 的分析（已定位根因但未完成修复）
- **相关代码：** `MainWindowNativeNode.ets` 中的 `expandedShell()`, `isUiPoint()`
- **参考：** WorkBuddy memory 2026-07-20.md "边边角角点不中" 分析

### 2. compactShell（竖屏/窄屏模式）未验证

- **状态：** 待验证
- **现象：** 当前只测试了横屏 expandedShell。compactShell（底部 Dock + 底部面板）是否正常未知
- **修复方向：** 在窄屏模拟器或旋转设备上测试；修复 compactShell 的触摸路由（如果有类似死区问题）
