# Stellarium 鸿蒙版 — 三端验收表（QA Checklist）

> 同一 `arm64` HAP 包通吃三端，但交互与传感器表现不同，需**逐端逐项**验收。
> 用法：在 `[ ]` 里打 `x` 表示通过（`[x]`），`?` 表示待定，`!` 表示失败待回填。
> 失败项请按 `TROUBLESHOOT.md` 把报错贴回 AI。

通用说明：
- 出包：Phase 2 编译生成的 `build/libstellarium-harmonyos` 工程可成功产出 HAP。
- 渲染：打开后能看到星空，无黑屏 / 花屏 / 着色器报错。
- 触屏：手机/平板单指拖拽旋转、双指捏合缩放；电脑鼠标拖拽 + 滚轮缩放。
- 传感器：陀螺仪/加速度计「指哪看哪」（设备朝向决定视野方向）。
- 星表：默认星表加载、可选在线星表/更新正常。
- 性能：流畅度（目标 ≥ 30fps，理想 60fps）。
- 权限：首次运行权限弹窗正常、可授予。
- 稳定性：连续运行无明显崩溃 / 内存泄漏 / 卡死。
