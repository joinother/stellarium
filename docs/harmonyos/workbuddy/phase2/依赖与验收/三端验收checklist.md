# Stellarium 鸿蒙移植 — 三端验收 Checklist（Phase 2）

> 验收范围：手机（Phone）/ 平板（Tablet）/ 电脑（鸿蒙 arm 架构 PC）三端，统一 arm64-ohos 包。
> 编制方：多端质检（严三端）
> 说明：标注「三端通用」为必验；标注「仅电脑」仅电脑端验证；标注「触屏端」指手机/平板。

---

## 一、编译出包（三端通用）
- [ ] `harmonydeployqt` 成功产出 HAP（手机/平板）与可安装工程/包（电脑）
- [ ] 全部替换后的 Qt 模块（Sensors/Charts/SVG/Multimedia/Concurrent）正常链接
- [ ] 冲突模块已移除：WebEngine / Positioning / SerialPort / VirtualKeyboard / TextToSpeech / 旧 OpenGL 无残留引用
- [ ] 渲染主干已改 QtGui OpenGL（RHI）路径，无旧 OpenGL 编译报错
- [ ] 包体积检查：ICU data、星表基础包体积在可接受范围

## 二、安装到设备/模拟器（三端通用）
- [ ] 手机：HAP 安装到真机/模拟器成功，可启动
- [ ] 平板：HAP 安装到真机/模拟器成功，可启动
- [ ] 电脑：安装/运行到鸿蒙 arm 设备成功，可启动
- [ ] 启动无闪退，首屏正常进入主界面

## 三、星空渲染正确（三端通用）
- [ ] 启动后星空正常渲染，无黑屏
- [ ] 无花屏、纹理错乱、UV 翻转异常
- [ ] 无着色器编译/链接报错（核心 Profile 着色器迁移验证）
- [ ] 星座连线、星名标签、地平线、天顶方向正确
- [ ] 昼夜/大气辉光（若接入 ShowMySky）无明显异常；未接入时用兜底天光正常

## 四、触屏 / 指针交互
### 触屏端（手机 / 平板）
- [ ] 单指拖拽：星空随手指旋转（赤道仪/方位跟随正确）
- [ ] 双指捏合：缩放视野（放大/缩小流畅，无跳变）
- [ ] 双击/长按：呼出菜单或星体信息卡正常
### 仅电脑
- [ ] 鼠标左键拖拽旋转星空
- [ ] 滚轮缩放视野
- [ ] 键盘输入（城市搜索、坐标输入）可被系统输入法/物理键盘接收

## 五、传感器「指哪看哪」（触屏端，需 ACCELEROMETER / GYROSCOPE 权限）
- [ ] 首次进入已申请加速度计/陀螺仪权限，弹窗说明清晰
- [ ] 授权后开启 Qt Sensors（libohsensor）方向跟踪
- [ ] 设备转动时视场方向实时跟随（指哪看哪）
- [ ] 权限被拒时降级为手动拖拽，不崩溃
- [ ] 电脑端（无传感器）：该项标记 N/A，验证手动控制正常

## 六、星表加载（三端通用）
- [ ] 基础星表随包内置，启动即加载，星数正确
- [ ] 按需下载扩展星表（深空/额外星表）流程可用（HTTPS via OpenSSL 或 ArkWeb）
- [ ] 下载失败时给出明确提示，不卡死
- [ ] 已下载星表本地缓存生效，二次启动免重复下载

## 七、性能与流畅度（三端通用）
- [ ] 帧率稳定（手机/平板目标 ≥ 30fps，电脑目标 ≥ 60fps）
- [ ] 长时间运行无明显掉帧、内存增长可控
- [ ] 缩放/拖拽高星数场景下无明显卡顿
- [ ] 设备温度/功耗在可接受范围（触屏端）

## 八、权限弹窗与说明（三端通用）
- [ ] 定位权限：若保留手动输入则无需定位；若用 NDK 定位，弹窗说明用途
- [ ] 传感器权限：加速度计/陀螺仪用途说明清晰
- [ ] 存储/下载权限：扩展星表下载说明清晰
- [ ] 系统输入法接管正常，输入框可唤起软键盘（触屏端）

## 九、崩溃 / 稳定性（三端通用）
- [ ] 冷启动、热启动各 5 次无崩溃
- [ ] 前后台切换（触屏端）、息屏恢复无崩溃
- [ ] 异常网络/无网络下下载星表不崩溃
- [ ] 权限拒绝路径下主流程可用不崩
- [ ] 日志可采集，关键崩溃有可复现步骤记录
