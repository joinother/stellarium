# Stellarium 鸿蒙移植 — 依赖交叉编译清单（Phase 2）

> 路线：A（Qt 整包移植）。目标架构统一为 **arm64-ohos** 一套包，覆盖手机 / 平板 / 电脑（鸿蒙 arm 架构）三端。
> 编制方：依赖交叉编译（赖库通）+ 多端质检（严三端）
> 适配基线：Qt 6.12 HarmonyOS。已知不支持：WebEngine / Positioning / SerialPort / VirtualKeyboard / TextToSpeech / 旧 Qt OpenGL 模块。
> 已知支持：Qt Sensors（libohsensor）/ Qt Charts / Qt SVG / Qt Multimedia / Qt Concurrent。

---

## 一、第三方库

### 1. zlib
- **用途**：Stellarium 数据解压、PNG/纹理压缩、内部资源读取的基础压缩库。
- **鸿蒙适配状态**：✅ 已被 `ohos-additional-packages` 直接覆盖。
- **处理建议**：直接复用官方包，CMake 用 `find_package(ZLIB)`，无需自行交叉编译。
- **优先级**：高

### 2. libpng
- **用途**：星空纹理、UI 图标 PNG 解码。
- **鸿蒙适配状态**：✅ 已被 `ohos-additional-packages` 直接覆盖（依赖 zlib）。
- **处理建议**：直接复用，确保与 zlib 版本匹配即可。
- **优先级**：高

### 3. freetype
- **用途**：矢量字体栅格化，星名/标签渲染的核心。
- **鸿蒙适配状态**：⚠️ 需 vcpkg OHOS 交叉编译（triplet `arm64-ohos`）。不在官方 additional 默认列表重点项，建议走 vcpkg。
- **处理建议**：`vcpkg install freetype --triplet arm64-ohos`，注意与 fontconfig 联动、关闭自带 harfbuzz 冲突（或同时纳入 harfbuzz）。
- **优先级**：高

### 4. fontconfig
- **用途**：字体发现与匹配，决定中英文/符号字体回退策略。
- **鸿蒙适配状态**：✅ 已被 `ohos-additional-packages` 覆盖（但需确认鸿蒙系统字体目录挂载与配置路径适配）。
- **处理建议**：复用官方包；额外验证 `FONTCONFIG_PATH` 在鸿蒙沙箱内的可读性与缓存目录写入权限。
- **优先级**：高

### 5. ICU
- **用途**：Unicode 处理、本地化/翻译、排序与区域格式化（Stellarium 多语言）。
- **鸿蒙适配状态**：✅ 已被 `ohos-additional-packages` 覆盖。
- **处理建议**：直接复用；注意 `data` 切分（common/stub），减少包体积。
- **优先级**：高

### 6. OpenSSL
- **用途**：在线星表/扩展资源下载 HTTPS、网络校验。
- **鸿蒙适配状态**：✅ 已被 `ohos-additional-packages` 覆盖。
- **处理建议**：直接复用；如走 ArkWeb 下载可替代部分 HTTPS 逻辑，但仍保留 OpenSSL 用于本地校验。
- **优先级**：高

### 7. QXlsx
- **用途**：读写 Excel（部分导入导出/星表工具脚本用）。
- **鸿蒙适配状态**：⚠️ 需 vcpkg OHOS 交叉编译（纯 Qt 库，依赖 Qt Core/Gui，风险低）。
- **处理建议**：`vcpkg install qxlsx --triplet arm64-ohos`；若仅桌面工具用、移动端非必需，可评估后置或封装为可选模块。
- **优先级**：中

### 8. INDI
- **用途**：天文设备（望远镜/相机/赤道仪）控制协议，桌面端望远镜联动。
- **鸿蒙适配状态**：🔧 移动端可禁用不编译（与 Qt SerialPort 一同移除）。
- **处理建议**：定义 `STELLARIUM_WITH_INDI` 开关；移动端（手机/平板）默认关闭，电脑端若需望远镜控制则 vcpkg 交叉编译（+ 串行依赖由 NDK/蓝牙替代）。
- **优先级**：中（手机/平板=低，电脑端望远镜场景=中）

### 9. ShowMySky（glm / eigen3）
- **用途**：大气散射/天空辉光物理模型，提升地平线附近天光真实度。
- **鸿蒙适配状态**：⏱️ 大气模型，可后置（非首版必选项）。glm/eigen3 为头文件库，交叉编译成本极低。
- **处理建议**：glm/eigen3 用 vcpkg 头文件包（`arm64-ohos`），ShowMySky 本身可放 Phase 3 接入；首版用简化的固定天光着色器兜底。
- **优先级**：低（首版）/ 中（增强版）

### 10. libexiv2
- **用途**：图片 EXIF 元数据读取（用户导入观星照片/星图叠加）。
- **鸿蒙适配状态**：⚠️ 需 vcpkg OHOS 交叉编译。
- **处理建议**：`vcpkg install exiv2 --triplet arm64-ohos`，注意 zlib/libpng 依赖一致性；若首版无照片导入可后置。
- **优先级**：中

### 11. nlopt
- **用途**：非线性优化（部分轨道/对准算法可选依赖）。
- **鸿蒙适配状态**：⚠️ 需 vcpkg OHOS 交叉编译（C/C++ 库，体积小，编译简单）。
- **处理建议**：`vcpkg install nlopt --triplet arm64-ohos`；若 Stellarium 仅弱依赖，可先关闭并打桩。
- **优先级**：低

## 二、Qt 模块冲突项

### 12. Qt WebEngine（在线百科）
- **用途**：Stellarium 内置 Wiki/在线百科网页浏览。
- **鸿蒙适配状态**：❌ Qt 6.12 HarmonyOS 不支持 WebEngine。
- **处理建议**：移动端禁用在线百科模块；改走 **ArkWeb**（鸿蒙系统 Web 组件）以外部/内嵌方式打开在线资料，或改为本地静态百科包。
- **优先级**：高

### 13. Qt Positioning（GPS）
- **用途**：设备 GPS 自动定位用户经纬度，用于初始化观测点。
- **鸿蒙适配状态**：❌ Qt 6.12 HarmonyOS 不支持 Positioning。
- **处理建议**：移除 Qt Positioning 依赖；改为 **手动输入经纬度/城市选择**，或调用鸿蒙 NDK/系统定位 API（单独封装定位服务）回写坐标。
- **优先级**：高

### 14. Qt SerialPort（望远镜）
- **用途**：串口连接赤道仪/望远镜控制器（INDI 底层）。
- **鸿蒙适配状态**：❌ Qt 6.12 HarmonyOS 不支持 SerialPort；移动端望远镜功能禁用。
- **处理建议**：移动端整模块禁用；电脑端如保留望远镜，改用 NDK 串口/蓝牙 API 封装或跳过。与 INDI 联动处理。
- **优先级**：中（手机/平板=低）

### 15. Qt VirtualKeyboard
- **用途**：内置虚拟键盘（输入框/搜索）。
- **鸿蒙适配状态**：❌ Qt 6.12 HarmonyOS 不支持 VirtualKeyboard。
- **处理建议**：复用**鸿蒙系统输入法**（软键盘由系统接管），Qt 侧关闭 `QT_IM_MODULE` 内置键盘；确保 `TextInput`/`LineEdit` 能唤起系统键盘。
- **优先级**：高

### 16. Qt TextToSpeech
- **用途**：语音报星名/朗读（无障碍）。
- **鸿蒙适配状态**：❌ Qt 6.12 HarmonyOS 不支持 TextToSpeech。
- **处理建议**：整模块禁用；如需无障碍语音，改接鸿蒙系统 TTS（单独封装），首版不实现。
- **优先级**：低

### 17. 旧 Qt OpenGL 模块
- **用途**：Stellarium 旧渲染路径直接调用 `QOpenGLFunctions`/旧 `QtOpenGL` 类。
- **鸿蒙适配状态**：❌ 旧 Qt OpenGL 模块不可用。
- **处理建议**：改写为 **QtGui 的 OpenGL（QOpenGL*/QRhi/RHI）** 渲染路径；统一改用 `QOpenGLWindow`/`QOpenGLWidget` + `QOpenGLExtraFunctions`，着色器迁移到核心 Profile。这是渲染主干改造，优先级最高。
- **优先级**：高
