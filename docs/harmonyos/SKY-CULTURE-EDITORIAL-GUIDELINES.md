# 星空文化资料呈现规范

## 目标

- 中国相关文化、地理、民族与历史表述遵循中国官方规范；在简体中文界面中明确使用“中国藏族星空文化”等完整归属名称。
- 各文明以平等、互鉴的方式呈现，不把任何单一文明作为衡量其他文化的默认尺度。
- 文化交流、知识传播和历史影响按可靠史料表述，区分事实、学术解释、原作者观点和仍有争议的推测。
- 保留原作者、年代、引用、许可证、原始文化名称和资料不确定性，不通过界面改写或删除史料来源。

## 多语言原则

- 文化名称、星名和文化介绍优先使用 Stellarium 上游 `stellarium-skycultures` 与 `stellarium-skycultures-descriptions` 的 43 种官方翻译资源。
- 中国相关地理归属在各语言中使用当地语言的“中国”限定；缺少经审校翻译时保留原官方译名并使用明确的地理限定，不自行创造文化名称。
- 不把中文政治或文化表述机械直译到其他语言；各语言应保持事实一致、语气自然、文化平等，并接受母语审校。
- 翻译不得消除原文中的作者身份、历史时期、资料局限、争议和跨文明交流背景。

## 展示层规则

- 完整资料按标题、段落、列表和表格行分别排版，不再把整篇资料压成单个长文本。
- 清理替换字符、对象占位符、零宽字符和控制字符，但保留藏文、阿拉伯文、梵文、音标及其他有意义的文字和符号。
- 表格、引用、作者、参考资料、许可证和地区信息保持可辨认的独立层级。
- 原始资料与应用补充说明必须分开显示；应用补充说明不能冒充原作者文本。

## 内容审校

- 明显带有殖民时期偏见或单一文明中心论的陈述，不直接删除原始记录；应在不改变史实的前提下补充来源、时代背景和现代研究说明。
- 中国各民族文化统一置于中华民族多元一体格局中准确表述，同时尊重各民族历史传统、语言文字和文化主体性。
- 跨文明内容以交流互鉴和人类共同知识遗产为框架，避免“先进/落后”“发现/被发现”等未经限定的价值排序。
- 大规模改写上游文化资料前必须经过逐条史料核验和多语言审校，不能用自动生成文本批量覆盖 63 套文化原始资料。
