## 防护与恢复

1. 读取 SGP4 错误码；拒绝非有限位置/速度，避免将失败后的旧向量当作新结果。
2. 采用地心半径低于地球半径加 80 公里的保守限制；原有地理高度检查仍保留。
3. 增加严重外推发散保护：传播半径超过 TLE 历元远地点地心半径的两倍时返回 `divergent_extrapolation`。这是应用保守合理性筛查，**不是 SGP4 标准错误码，也不是定位精度保证**。按每条轨道自身尺度比较，不用低轨固定高度上限误杀同步轨道或大椭圆轨道。
4. 不通过任意减慢动画、裁切角速度或强行降低高度掩盖错误。正常低轨目标允许快速运动，分辨率和画质不变。
5. 无效目标停止星图标记、点选命中、选中框和连接线投影，不提供距离、当前坐标或虚假过境。目录、TLE 和轨道原始参数仍可查。
6. 不永久修改用户的显示开关，不在一次传播失败后停止后续计算。时间返回有效区间，或者导入新 TLE 后重新计算，可自动恢复。
7. 修复 TLE 年龄计算原来丢失时分秒和混用儒略日正午的问题。超龄仅作警告，不一律删除所有旧 TLE；30 天沿用现有插件过期阈值，不代表 30 天内必然准确。

## CLI 与界面

- `getSelectedObjectInfo`：`orbitValid`、`propagationStatus`、`tleAgeDays`、`tleOutdated`、`sgp4Error`。失败时 `distanceStatus=invalid_orbit`，无假距离/坐标。
- 居中和开启跟踪命令对无效卫星返回 `errorCode=invalid_orbit`，搜索保留资料选择但不自动移动视角；避免以未初始化或旧方向推动相机。
- `getSatellites`：每项包含有效性、传播状态、实际 TLE 年龄；无效轨道不返回旧高度。
- `getSatelliteDetail/getSatellitePasses`：`dataStatus=invalid_orbit/stale/local`；不能将无效计算下的空列表称为“未来没有过境”。
- 观测、坐标、资料页面提示异常或旧 TLE，并提示导入本地数据/回到历元附近。新增文字提供英、简繁中文，其余语言沿用英语回退，不宣称已全语言人工翻译。

## 数据与科学边界

本次只更新上述一条已核验的新 TLE，不伪造历元、不开放运行时联网。网页检索接口首次失败，随后构建机直接下载成功；其余 149 条异常仍须按来源、历元和实际在轨状态逐项更新或确认，不用新数据的成功掩盖其他记录缺口。

没有修改整个目录的 `offlineSnapshot` 来触发旧的整表覆盖。新增同快照内的逐条更新：只把更晚历元的内置 TLE 两行合入已安装的同 ID 记录，保留用户显示、分组、名称和其他设置，跳过用户锁定记录，不覆盖用户已导入的更新 TLE。已有“快照不同整表替换”的历史路径本次未重构，仍需后续单独审计，不能将本次安全增量策略扩大为所有升级路径均安全。

回归期间遇到一项 CLI 参数缺陷：`encodeURIComponent` 不编码括号等 Shell 特殊字符，导致 `ISS (ZARYA)` 无法发出命令；已补严格编码并加入往返测试。

还复现了无效卫星被选择时的 SIGSEGV。直接读取故障目录被拒绝后，经华为 MCP 查询并读取《hidumper》全文，使用 API 22 起支持的 `hidumper -e --print com.joinother.skyinstrument -n 2` 成功取到完整故障栈：`StelCore::getIAUConstellation → ConstellationMgr::isObjectIn → setSelected → StelObjectMgr::setSelectedObject`。无效方向进入未作边界保护的星座查询，嵌套 while 越界。已对零/非有限方向返回空结果，并用有界的半开赤经区间查表替换不受限的下标扫描；星座文化凸包查询同样拒绝无效方向。新增全天天区网格、零时赤经和南北极回归，不以客户端重试掩盖进程重启。
