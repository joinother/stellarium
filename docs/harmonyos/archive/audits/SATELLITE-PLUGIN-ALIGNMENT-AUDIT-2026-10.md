# Satellites 插件与原版 GUI 对齐审计

审计日期：2026-10-01

对照对象：原版 `plugins/Satellites/src/gui/SatellitesDialog.cpp`、对应 Qt Designer 界面，以及鸿蒙端 `MainWindowNativeNode.ets` 与 `StelMainView.cpp` 的命令桥。

## 本轮已对齐

- 卫星来源列表改为固定高度的内层滚动区域；长 URL 默认显示“主机 · 路径”，点按后才展开完整地址，避免来源数量或地址长度撑开整个面板。
- 来源开关保留原版 `0,`/`1,` 语义：仅在“自动加入新卫星”开启时使用来源开关；切换后仍保留其他来源的启用状态。
- 增加来源编辑、删除和恢复默认来源；恢复默认来源通过原生 `restoreDefaultTleSources()`，不是在 ArkTS 端复制一份可能过期的默认 URL。
- 增加与原版一致的更新状态提示：联网更新关闭、更新中、更新错误、不到 1 分钟、分钟和小时倒计时。
- 来源类别、添加、编辑、保存、删除、恢复和状态提示已加入当前鸿蒙端 UI 多语言表。来源 URL 本身是数据，不对域名、路径或 TLE 文件名做机器翻译。
- 本地 TLE 导入、在线更新开关、自动加入、自动移除、自动显示、更新周期、卫星分组筛选、名称/NORAD 检索、轨道线和可见性开关继续使用原生命令桥。

## 与原版仍有明确差异

以下项目已记录为后续适配项，本轮不通过伪造按钮宣称已经完成：

1. 原版卫星编辑页可以直接编辑选中卫星的名称、描述、TLE 两行、标准星等、雷达截面、近地点、远地点、周期、分组和通信信息；鸿蒙端目前提供结构化详情和 TLE 展示，但还没有安全的逐字段编辑/保存页。
2. 原版支持自定义分组的创建、重命名和成员勾选；鸿蒙端目前支持原生分组列表、筛选和检索，尚未暴露分组管理编辑器。
3. 原版的 Iridium flare 预测、表格选中跳转和 CSV/XLSX 导出在鸿蒙端还没有独立面板；需要先确认当前构建是否启用对应 Iridium 模块，再决定采用本地计算、CSV 导出或移植 XLSX 依赖。
4. 原版来源列表的 Qt 复选框、编辑、删除和恢复默认行为现在已覆盖；但鸿蒙端仍需要补一次设备端可用性验收，尤其是长按/触摸滚动与 Toggle、编辑、删除按钮的事件隔离。
5. 原版关于页包含完整插件说明和可观测性帮助；鸿蒙端已有统一插件元数据展示，但尚未把 Satellites 的全部专属帮助段落拆成独立的卫星帮助页。

## 本地化规则

- UI 文案按当前 ArkTS 的语言表处理，当前明确维护英语、简体中文、日语、韩语、法语、德语、西班牙语和俄语；其他语言沿用 `I18n` 的回退链，不把 URL 或用户导入的 TLE 内容翻译后再保存。
- 卫星名称本地化属于数据层：优先使用原生对象的本地化名称、中文别名和 NORAD 编号；来源地址、TLE 行、发射机构代号等保持原文，避免破坏检索和轨道解析。
- “自动加入新卫星”与单个来源开关是两个层级，翻译中明确说明其关系，避免用户以为关闭全局开关会删除来源。
