# 更多设置审计

更新时间：2026-08-30

## 本轮结论

“更多设置”当前已经有统一的设置面板，但原版桌面配置项并不是全部适合直接搬到移动端。当前优先保证每个可见开关都连接 Stellarium 核心或插件的真实状态，不用 ArkUI 本地变量冒充功能状态。

本轮修复了三个直接影响用户的缺口：

- “自动缩放复位方向”从原生 `getNavigationSettings` 返回值回填，重新打开设置时不再显示旧值。
- 修改“自动缩放复位方向”后，成功回调立即回写本地状态，避免 Toggle 点击后重建又跳回原状态。
- 插件管理加入统一设置页的可见标签；仍只管理启动加载，不复制插件功能开关。
- 图层旧兼容入口与统一设置页的黄道光亮度范围统一为 `0..5`，避免同一原生属性在不同入口出现两套上限。

## 原版差距与分期

### P0：先保证不误导用户

- 每个异步设置请求都应有“读取中/应用中/失败回滚”状态；当前部分滑杆已回滚，后续应统一到所有设置行。
- 语言切换后，设置标签、按钮和当前值需要同一轮重建；不得缓存首次语言。
- 插件管理继续只负责生命周期；目镜、卫星、流星雨、角度测量等功能开关必须留在各自功能面板。

### P1：补齐高价值的原版设置

原版 `src/gui/configurationDialog.ui` 中仍有移动端尚未提供独立控件、但可通过真实核心属性接入的项目：

- 动力学滚动、鼠标超时、鼠标导航与缩放的细分行为。
- 折射、视差、光行差、章动和地心/地表观测等计算选项。
- 最小/最大 FPS 意图、球面镜、日期旋钮自动聚焦和赤道仪模式提示。
- 屏幕/GUI 字体大小、按钮缩放和截图格式、颜色反转、自定义尺寸、DPI。

这些项目不能只新增 Toggle。接入前需要为核心属性补充成对的 getter/setter 和明确的“立即生效/重启生效”说明；其中截图和字体设置还要先确认 HarmonyOS 渲染路径是否支持对应语义。

### P2：整理兼容入口

- `settings_quick_legacy` 和历史 `config` 路由继续只作为旧命令/书签兼容，不再增加新功能。
- 工具、脚本和插件不在设置页复制第二套业务面板。
- 删除旧兼容 Builder 前，先保留 CLI 动作 ID、状态迁移和已有书签兼容测试。

## 验收清单

- 设置页重新打开后，自动缩放复位方向与核心状态一致。
- 插件管理可以从设置页标签进入，也可以从“更多功能”进入同一页面。
- 统一设置和图层兼容入口对黄道光亮度使用相同范围。
- 不修改签名、证书、Provision、隐私/SN 和联网策略。
- 源 ArkTS 与 `build/libstellarium-harmonyos` 生成工程保持一致，并通过 ArkTS、资源、国际化和 HAP 构建检查。
