# Stellarium HarmonyOS 上架合规与华为应用检测指南

> **创建时间：** 2026-07-27
> **适用场景：** 个人开发者上架华为应用市场（AppGallery）

---

## 1. 个人开发者上架限制

### 1.1 ICP备案与联网

| 限制 | 说明 | 影响 |
|------|------|------|
| 个人开发者无ICP备案 | 不能提供需要备案的联网服务 | 上架版本**不能有联网功能** |
| 应用不能有用户注册/登录 | 个人开发者应用不允许有账号体系 | 本应用无账号系统，符合要求 |
| 不能有支付功能 | 个人开发者不能接入支付 | 本应用免费无支付，符合要求 |

### 1.2 上架版本必须移除的联网功能

| 功能 | 处理方式 |
|------|----------|
| 星表下载（getStarCatalogs） | **移除UI入口**，编译时用product配置关闭 |
| 卫星TLE数据更新 | **移除UI入口**，卫星功能仅用内置数据 |
| LX200望远镜控制（TCP） | **移除UI入口**，局域网通信也算联网 |
| GPS定位 | **保留**，系统定位服务不需要ICP备案 |

> **关键：** 上架版本的 `module.json5` 中应移除 `ohos.permission.INTERNET` 权限，只保留定位权限。

### 1.3 版本管理

```
openharmony-preview-v1     → 开发版（含联网功能，仅自用/测试）
harmonyos-release           → 上架版（不联网，提交华为审核）
```

编译时通过 `build-profile.json5` 的 product 配置区分：

```json5
"products": [
  { "name": "default", "target": "default" },           // 开发版
  { "name": "release", "target": "release" }             // 上架版（无联网）
]
```

## 2. 华为应用检测要点

### 2.1 安全检测

| 检测项 | 要求 | 当前状态 |
|--------|------|----------|
| 应用签名 | 必须使用华为CA签发的发布证书 | ❌ 未配置发布签名 |

| 无恶意代码 | 不含病毒/木马 | ✅ 纯开源代码 |
| 数据安全 | 不泄露用户隐私 | ✅ 不收集用户数据 |
| 加密合规 | 不使用不安全加密算法 | ✅ 使用系统加密 |

### 2.2 兼容性检测

| 检测项 | 要求 | 当前状态 |
|--------|------|----------|
| API版本兼容 | 支持目标API版本 | ✅ API 24 |

### 2.3 性能检测

| 检测项 | 要求 | 当前状态 |

### 2.4 内容检测

| 检测项 | 要求 | 当前状态 |
|--------|------|----------|

## 3. 上架前检查清单

### 3.1 必须完成项

- [ ] **包名规范化：** `org.qtproject.example.stellarium` → `org.stellarium.app`
  - 修改 `AppScope/app.json5` 的 `bundleName`
  - 修改 `entry/src/main/module.json5` 的 `bundleName`
  - 重新配置签名（包名变更后旧签名失效）
  - **注意：包名一旦上架不可更改**

- [ ] **隐私政策：** 创建 `docs/PRIVACY-POLICY.md` 并用 GitHub Pages 托管
  - 内容：位置信息使用说明、不收集用户数据声明、无第三方追踪SDK
  - URL: `https://joinother.github.io/stellarium/privacy`

- [ ] **华为发布签名：**
  1. 登录 [AppGallery Connect](https://developer.huawei.com/consumer/cn/agconnect/)
  2. 创建 HarmonyOS 应用
  3. "用户与访问" → "证书管理" → "新增证书"
  4. "HarmonyOS 应用" → 创建 Profile
  5. 下载 `.cer` 和 `.p7b`
  6. 在 `build-profile.json5` 配置 release signingConfig

- [ ] **Release构建：**
  ```bash
  hvigorw assembleHap --mode module -p product=release --no-daemon
  ```

- [ ] **应用图标：** 216×216px PNG（✅ 已完成，使用原版Stellarium图标）

- [ ] **截图：** 至少3张，2340×1080（Pad横屏）
  1. 星图主界面（星座连线 + 行星标签）
  2. 天体详情（选中木星，展示信息面板）
  3. 搜索/分类浏览面板
  4. 今夜天象面板
  5. 时间控制面板

- [ ] **应用描述：**
  - 中文名：星图
  - 英文名：Stellarium
  - 简介：开源天文星图软件，支持实时星图渲染、天体搜索、时间控制等功能

- [ ] **GPLv2许可证声明：**
  - 应用内"关于"页面显示许可证文本
  - 应用描述中注明源码地址

- [ ] **内容分级：** 所有人（天文教育类）

- [ ] **权限精简：** 上架版只保留 `ohos.permission.LOCATION`，移除 `ohos.permission.INTERNET`

- [ ] **应用体积评估：** 当前460MB
  - 考虑将大星表数据从HAP中移除，首次使用时本地内置即可（不联网下载）
  - 或接受460MB体积（华为应用市场无硬性体积限制，但过大影响下载意愿）

### 3.2 华为应用检测可能被拒的常见原因

| 风险项 | 严重程度 | 处理建议 |
|--------|----------|----------|
| 包名含 `qtproject.example` | 高 | 必须改为正式包名 |
| 未提供隐私政策 | 高 | 必须提供URL |
| INTERNET权限但无ICP备案 | 高 | 上架版移除联网权限 |
| 首次启动过慢（资源提取） | 中 | 优化首次启动体验，添加进度提示 |
| 应用体积过大 | 中 | 评估是否精简 |
| 无适龄分级 | 中 | 填写"所有人" |
| 截图与实际不符 | 中 | 用真机/模拟器截图 |
| 缺少 GPLv2 声明 | 中 | 在关于页面和描述中声明 |

### 3.3 华为应用检测流程

1. 在 AppGallery Connect 提交应用
2. 自动检测：签名、权限、API兼容性、安全扫描
3. 人工审核：内容合规、版权、隐私
4. 审核周期：通常 1-3 个工作日
5. 被拒后可修改重新提交

## 5. 当前项目差距评估

1. ❌ 包名未规范化
2. ❌ 无隐私政策
3. ❌ 无华为发布签名
4. ❌ 上架版未移除联网功能
5. ❌ 未准备截图
6. ❌ 未构建 Release HAP

1. ⚠️ 应用体积460MB较大
2. ⚠️ 首次启动需提取资源（可能较慢）
3. ⚠️ 陀螺仪未真机测试
4. ⚠️ TTS语音播报不可用（需HMS SDK）

1. ✅ 应用图标（原版Stellarium图标）
2. ✅ GPLv2开源合规
3. ✅ 内容分级（所有人）
4. ✅ 无账号/支付系统
5. ✅ 无第三方追踪SDK
6. ✅ 帧率达标（61 FPS）
