## 兼容性与原则

- `getScriptList` 的 `items` 仍是原来的文件名数组；新增 `details` 不破坏旧 CLI 客户端。
- 没有元数据时显示“原版未提供”，不根据文件名推测作者或许可证。
- 资源内容、原作者署名、许可证和来源链接必须保留；运行时继续离线，不新增网络请求。
