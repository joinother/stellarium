## 简介

星象仪是 Stellarium 的 HarmonyOS 发行版，是一款完全离线运行的开源天文星图应用。它根据时间和观测地点呈现真实星空，支持天体搜索、时间旅行、观测地点选择、星体详情、图层控制和陀螺仪观星。所有天文计算与数据均在设备本地完成。

## 隐私政策

当前版本使用 AGC 隐私托管；应用内“设置 → 关于 → 开发者隐私政策”跳转华为应用市场详情页查看当前生效版本。发布新版本时需同步 `harmonyos/module.json5` 的 `appgallery_privacy_link_privacy_statement` 协议链接。
