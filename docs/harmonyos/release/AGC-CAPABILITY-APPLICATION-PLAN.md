## 申请范围与边界

用户确认的未来能力范围为：实况窗、代理提醒、优先通知、锁屏卡片、待机屏保卡片、背板透明卡片、接续服务。

这些项目不是普通的“打开开关”权限。AppGallery Connect 会先显示申请规则，部分能力还要求提交业务原因、场景截图、UX 设计或方案材料，经审核通过后，才能勾选能力开关并重新生成 Profile。当前页面中的“未申请”不能当作已开通，不能为了省一次操作而伪造审批状态。

| --- | --- | --- |

## 实施原则

1. 不申请室内高精度定位、位置语义、蓝牙真实 MAC 扫描、运动健康、Wear Engine、钱包等与当前星图业务无关的能力。
2. 普通望远镜局域网/串口控制和未来星闪控制属于本地设备连接，不通过 AGC 公网能力替代，也不以此申请蓝牙扫描用户识别权限。
3. 实况窗、代理提醒、锁屏卡片等审核通过后，统一更新隐私政策、应用权限清单、`module.json5`、功能开关和 Profile；未获批时保持不可调用和默认关闭。
4. 能力实际获批、启用并保存后，集中重新生成匹配的 Debug/Release Profile，再构建和真机回归；退回、补材料或仍在审核不触发 Profile 更新，不提前改动现有签名。

## 官方文档核对

- `liveview-formal-authority`：实况窗正式权益需要先联调，再提交场景、接入方案和自验收结果，审核周期以平台实际结果为准。
- `agent-powered-reminder`：代理提醒需要业务申请、场景截图、应用分类信息，并申请对应权限；通过后才可打开能力开关。
- `arkts-ui-lockscreen-form-development`：锁屏卡片需要 Form Kit 配置和开放能力申请，审核通过后才能接入 Profile。
