## 安全与便利性的判断

当前需要的是减少耦合：内容审核、在线探活、天气功能检测、入侵防护分别做各自的事。
给少量自有静态网页反复做全站 AI 审核，收益不高；把它与会回源的业务探针放在一起会产生费用与误报循环。
已经保留规则巡检、内容变化检查、TLS、入口限流和日常报告，优先修掉循环，不删除所有防护。

还不能称“安全已完善”的实际边界：

1. 公共天气端点没有用户身份额度；攻击者分散坐标仍能抢占公共预算。现在能限制本服务调用量，但正常用户可用性仍可能受影响。下一步按用户/会话分配额度，或接边缘防刷；不要用 App 内固定 Key 当身份认证。
2. 120 次/IP/小时可能影响多人共享网络；6 并发、90/min 在世界视图大扇出时也可能出现部分点无数据。根据真实缓存命中与活跃用户调整，不应为方便直接取消全局预算。
3. 预算为单进程文件状态，适用于这台单实例；多 worker/多机器前必须共享原子计数。限额保护失效时宁可暂不回源；负缓存和 IP 表仍在重启时重置。
4. 普通 skyops 身份与维护 root 分开使用，但现有云凭据仍可请求维护连接。脚本的身份检查不是云端不可越过的权限边界，后续应核实 RAM/OS 登录限制、独立维护凭据与临时凭据。
5. 今日有同机站点备份，脚本另向私有 Gitee 同步审计记录和哈希清单；这不等于完整业务异地备份。没有在本轮验证整机损毁恢复。当前备份脚本也未完整包含天气代码/配置；维护备份仅作本次回退。
6. 源码中的每周比对脚本与备份脚本覆盖目录不完全一致，存在误报风险，需要专项统一清单并做恢复演练。此次没有执行全量备份/恢复或调整其留存。
7. AI 判断可能误报或漏报，不应作为自动停站的唯一依据。今天现有处置记录为演练，没有因此次修复开启新的自动封禁。

| 选项 | 用途 | 当前建议与成本边界 |
| --- | --- | --- |
| [云监控 CMS](https://www.aliyun.com/product/cms) | 主机资源、可用性、日志/链路观测 | 优先选择少量必要指标及独立站点可用性告警；不直接开整套高频日志/AI 分析。页面有免费试用，不代表全部功能永久免费 |
| [云备份](https://www.aliyun.com/product/cloud-backup) / 私有 OSS 备份 | 异机恢复能力 | 优先级高于重复 AI 审核；先明确数据范围、加密、保留期和恢复演练，核对存储/恢复/流量费后选一种 |
| [ESA](https://www.aliyun.com/product/esa) | 边缘缓存、网站/API 防护及防刷 | 后续流量增长时优先评估。官方页面有免费版与收费套餐，免费版写的是测试流量，不能等同无限生产免费。接入前核实中国内地节点、流量、规则、超额处理、真实 IP 与源站绕过问题 |
| [WAF](https://www.aliyun.com/product/waf) | Web/API 攻击过滤 | 复杂登录/上传业务或明显攻击时评估；现在不为单机静态官网直接购买整套。它无法阻止服务器自己调用和风造成的费用 |
| [AI 安全护栏/内容安全](https://www.aliyun.com/product/lvwang) | UGC 或 AI 输入输出的专业审核 | 日后开放用户图片、文章等再按新增内容接入；仍须哈希去重与预算。官方提供资源包/购买入口，不视为免费 |
| [云安全中心](https://www.aliyun.com/product/sas) | 主机风险与安全运营 | 可用于减少自建主机巡检，但需确认版本覆盖、修复能力与报价，不能替代备份 |
| [SLS](https://www.aliyun.com/product/sls) / [操作审计](https://www.aliyun.com/product/actiontrail) | 脱敏日志集中留存、云控制面操作记录 | 选择性记录异常与汇总，按容量/保留期评估费用；避免采集 Key、精确位置和完整查询参数 |

推荐顺序：本轮本地逻辑止损 → 完整异机备份/恢复演练 → 少量独立监控 → 按流量接 ESA → 有 UGC 再采购内容审核。
当前无需因调用浪费升级 ECS、引入 Kubernetes 或 Redis；若扩成多实例，再换共享预算存储。
