# 星象仪 · 内容安全流程说明

> 适用对象：站点负责人、值班人员、备案/检查时的说明材料。
> 对应服务器：阿里云 ECS `i-uf68vk358s8l58afzswt`（cn-shanghai）。
> 文档基于 2026-11-11 的线上实际配置整理，命令与阈值均可复核。

---

## 1. 一句话概括

```
词库与规则做初筛 → 大模型判定严重度 → 高风险可自动拦截 → 邮件与日报分级通知
→ 处置留证可回滚 → 每日记录异地留存（Gitee 私有仓库）
```

设计原则三条：

1. **规则兜底、AI 补位**——AI 不可用时系统仍能检出，只是不再降噪；
2. **只有确认的风险才打扰人**——日常问题进日报，只有「高」等级才即时发信；
3. **处置只做可逆动作**——拦截单个路径，随时一键回滚，不删文件、不改数据。

## 2. 检测：三道入口

| 入口 | 触发方式 | 覆盖范围 | 频率 |
|---|---|---|---|
| **变更哨兵** `quickcheck` | 文件 size+mtime 变化 | 站点 + TLE 镜像 | 每 10 分钟 |
| **全量巡检** `content-audit` | 定时 | 站点 + 镜像 + 5 个接口 | 每日 07:48 |
| **全站轮审** `fullscan` | 定时抽样 2 页 | 页面全文（不依赖变更） | 每日 03:04 |

### 2.1 变更哨兵

```
算法：记录每个文件的 size+mtime，与上一轮比对；有差异才触发完整巡检
范围：从 nginx 配置解析 root/alias 得到的目录（当前为站点目录与 /srv/tle-mirror/v1）
跳过：03:15–03:30 备份窗口；发布进行中（publish.lock 存在）
限流：每小时最多触发 6 次完整巡检；被限流时**保留基线不动**，下一轮继续触发
```

> 注：限流时若更新基线，这次变更会被永久吞掉（演练中发现并修复的问题）。

### 2.2 全量巡检覆盖面

| 类型 | 处理方式 |
|---|---|
| 页面 `*.html` | 违禁词、变体、隐藏元素、外链白名单、个人信息、脚本注入 |
| 小数据文件（≤64 KB，如 manifest.json） | 中文词条匹配 |
| 大数据文件（星历 CSV，MB 级） | 跳过词条匹配，改为**结构校验**（见 2.4） |
| 图片 | 校验魔数与扩展名是否一致；检测内嵌 `<script`/`<?php` |
| 动态接口 | 请求 `/healthz`、`/v1/grid`、`/v1/week`、`/v1/world`、`/v1/wx`，校验状态码、JSON 可解析、体积与正文内容 |

### 2.3 全站轮审（每日全量）

```
每日 03:04 审全部 html 页面（当前 5 个），不再抽样
每页全文分段送审（最多 3 段 × 1200 字）
目的：把"历史遗留、一直没有改动"的内容也翻出来
```

实测：全站全审 12 秒，5 个页面全部给出结论，当日消耗约 10 次调用。

> 早前版本每天只抽 2 页（一周才轮完一遍），存在"老内容最长一周无人看"的真空档，
> 已改为全量。

### 2.4 镜像数据的结构校验

镜像由星历 CSV、天体目录 JSON 与 TLE 文本组成，实测 56 个文件、13 MB，
**中文字符数为 0**——这里没有"文案违规"的空间，真正的风险是"数据被改坏或被替换"。
因此不套用词条匹配，改为结构校验：

| 文件类型 | 校验内容 |
|---|---|
| CSV（星历） | 列数与表头一致、单行不超过 2 万字符、无明显控制字符 |
| JSON（天体目录） | 可解析、字符串字段不含 HTML 标签/外链、无超长文本 |
| 3LE（TLE 文本） | 1/2 开头行数配对、行不超过 300 字符、不含尖括号 |

实测：删掉 CSV 某行一列 → 报「CSV 列数不一致，第 5 行 16 列，表头 17 列」；
往 JSON 里塞 `<a href=...>免费领取</a>` → 报「数据文件含异常内容：含标签或外链」。

## 3. 判定：规则 + 大模型

### 3.1 词库

| 项 | 现状 |
|---|---|
| 规模 | 4,328 条（上游 10 类 + 本地核心词 164 条） |
| 来源 | `konsheng/Sensitive-lexicon`（jsDelivr 主源、Gitee 备源） |
| 更新 | 每周一 04:30 自动，带自愈（详见第 7 节） |
| 本地层 | `local-extra.txt`（追加）与 `local-exclude.txt`（排除），不会被上游覆盖 |

关键词库本身**只做初筛**：命中不等于违规，只说明"需要复核"。

### 3.2 变体归一化

匹配前对文本做归一化，用于抓绕过写法：

```
全角转半角 → 繁简映射（賭→赌、場→场、採→彩…）→ 去除空白与常见分隔符 → 小写
```

- 原始命中：记为「中」
- 仅变体命中：同样记为「中」，因为去符号可能让相邻字拼出词条（如「颜色情况」含「色情」）

### 3.3 大模型定级

| 场景 | 调用 | 作用 |
|---|---|---|
| 规则命中 | `judge()` | 判定真风险 / 误报 / 待确认 |
| 内容变更但词库未命中 | `judge_free()` | 自由审查：诱导导流、夸大宣传、隐藏推广、个人信息、与站点定位不符 |
| 整页轮审 | `review_full_page()` | 对历史内容做全文判断 |

**定级规则**：

| 判定结果 | 等级 | 后果 |
|---|---|---|
| AI 判 risk | **高** | 即时发信 + 可自动处置 |
| AI 判 false_positive | **低** | 只写报告与日报 |
| AI 不可用 / 拒答 | 保持「中」 | 只进日报，不即时打扰 |
| 硬风险（隐藏元素内含违禁词） | **高** | 规则直接定级，不采纳模型 |

> 「高」的含义是"确认有问题"，不是"词库碰巧命中"。

### 3.4 成本与预算

| 约束 | 值 |
|---|---|
| 每日调用上限 | 300 次 |
| 单次巡检模型总时长 | 90 秒 |
| 单次调用超时 | 20 秒 |
| 单次巡检最多复核 | 4 个文件 |

实测：平静日约 8 次调用、0.008 元；普通日 16 次、约 0.017 元；上限 300 次约 0.31 元。
用量写入 `ai-usage.json`，日报显示调用次数、token 与估算费用。

## 4. 处置：可逆拦截

### 4.1 前置条件

```
/etc/skyinstrument/remediate.conf   APPLY=1   ← 当前为 APPLY=0（演练，不实际拦截）
```

`APPLY=0` 时只记录「演练通过（未生效）」，不发拦截。

### 4.2 处置流程

```
确认「高」等级 + 可映射为站点路径
   ↓
每日配额检查（最多 3 次真实拦截）
   ↓
取证：复制文件 + SHA-256 + 当时报告 → /srv/skyinstrument/incidents/<时间戳>/
   ↓
写 nginx 规则：location = /xxx { return 503; }（同时覆盖带/不带扩展名两种 URI）
   ↓
nginx -t 语法检查 → 通过才 reload
   ↓
reload 后自检：探测本机站点，异常则立即撤销规则并再次 reload
   ↓
写台账 incident-log.tsv + 发一封告警邮件（含回滚命令）
```

### 4.3 为什么不删文件、不覆盖备份

| 方案 | 问题 |
|---|---|
| 删除被篡改文件 | 不可逆，取证机会消失 |
| 用备份覆盖 | 会把正常更新一起回退 |
| **路径返回 503** | 只影响单页、瞬间可撤销、其他页面照常 |

### 4.4 回滚

```bash
skyinstrument-incident --rollback <时间戳>
```

实测：拦截 `/privacy.html` 后首页 200、目标页 503；回滚后恢复 200。

### 4.5 处置边界

| 边界 | 说明 |
|---|---|
| 只处理站点路径 | `/srv/tle-mirror` 数据不自动拦截，避免打挂 App |
| 每日上限 3 次 | 防止批量误拦 |
| 已在拦截则跳过 | 不重复堆规则 |
| 镜像数据只告警 | 同上 |

## 5. 通知：分级

| 情形 | 通知方式 | 频率 |
|---|---|---|
| 一切正常 | 日报「全部正常」 | 每日 08:00 |
| 中等级问题（广告法用语、未登记外链等） | 只进日报 | 每日 08:00 |
| **高等级问题** | **即时邮件**（含回滚命令） | 同一路径 24 小时内只发一次 |
| 服务器关键项异常 | 即时邮件 | 磁盘≥85%、证书≤14 天、本机访问非 200、站点服务异常、备份>26 小时 |
| AI 层降级 | 只在日报标注 | 不即时打扰 |

统一经 `skyinstrument-notify` 发出，通道可扩展（邮件 / webhook / 应用推送网关）。

日报内容：AI 用量、当前生效拦截、服务器自检、内容巡检、巡检耗时、哈希比对、定时任务、最近处置记录。

## 7. 降级与自愈

| 故障 | 系统行为 |
|---|---|
| AI 服务不可用 / 预算耗尽 | 退回纯规则；非硬风险的高等级降为「中」；报告与日报标注降级原因 |
| AI 因内容过滤拒答 | 记为 refused，不当作风险也不当作正常，规则结论仍然生效 |
| 词库拉取失败 | 单类沿用旧版，其余照常更新 |
| 词库条数异常增长（>50%） | 拒绝更新，保留旧版 |
| 词库连续失败 3 次 | 即时通知 |
| 新词库导致异常翻倍 | 自动回滚词库；回滚失败才通知 |
| 巡检自身变慢 | 报告与日报显示耗时；超 60 秒在日报标红 |
| 处置配置写错 | reload 后自检站点，异常自动撤销 |

| 措施 | 值 |
|---|---|

## 10. 日常运维要点

```bash
# 查看最近一次巡检
tail -60 /srv/skyinstrument/security-records/content-audit-$(date +%Y%m%d).txt

# 手动跑一次巡检
skyinstrument-content-audit

# 查看当前生效拦截
grep location /etc/skyinstrument-website/conf.d/incident.conf

# 解除某次拦截
skyinstrument-incident --rollback <时间戳>

# 开启/关闭自动处置
printf 'APPLY=1\n' > /etc/skyinstrument/remediate.conf   # 开
printf 'APPLY=0\n' > /etc/skyinstrument/remediate.conf   # 关（演练）

# 词库手动更新
skyinstrument-lexicon-update --force

# 验证告警通道
skyinstrument-notify --level daily --subject 测试 --text "通道测试"
```

## 11. 已知边界

| 项 | 说明 |
|---|---|
| 检测窗口 | 最坏 10 分钟（哨兵周期） |
| 图片内容 | 只校验格式与夹带脚本，**不识别图像内容** |
| 大 CSV | 不做词条匹配，改为结构校验（列数/可解析性/异常字符串） |
| 子串匹配 | 「颜色情况」含「色情」这类误报无法从词库层根治，由 AI 降级 |
| 无 Service Worker | 已确认站点未注册 SW，改版后不会长期看到旧页 |
| 缓存 | 页面 no-cache；构建产物 1 年（文件名含哈希）；图片 7 天；星历 30 分钟 |
