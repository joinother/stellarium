# 3D constellation preview

Seven meshes generated by the developer in Tripo from the modern culture's
illustrations: And, Ant, Aps, Aqr, Aql, Ara and Hya. No Sky Guide mesh, material
or shader is included. The original illustrations and their attribution remain
in this culture; the developer's source ledger is `tripo-batch/archive/_manifest.csv`.
The manifest records the SHA-256 of each supplied final GLB and runtime mesh.
The supplied ledger does not establish additional Tripo service licensing terms.

Rebuild with Blender (no network or runtime Draco dependency):

```sh
blender --background --factory-startup -P scripts/prepare-constellation-models.py -- /path/to/tripo-batch/archive /path/to/stellarium-src/skycultures/modern
python3 scripts/test-constellation-models.py
```

SCM1 contains little-endian vertex/index counts, six float32 values per vertex
(image-space X/Y, front-positive depth, normal XYZ), then uint32 triangle indices.
Model bounds fit the nontransparent illustration bounds without changing aspect
ratio. For the current opaque source illustrations this uses the full image bounds,
not a foreground silhouette. Per-model anatomical anchor calibration remains future work.
The existing three Hipparcos artwork anchors determine the J2000 direction.
Depth provides self-occlusion, with a fixed soft blue-white light. Models stay
celestially anchored; this is not a freely rotating object-detail viewer.

The optional preview uses the constellation-art visibility, selection fade and
brightness. Other cultures and missing/invalid meshes retain 2D illustrations.
`setSkyCultureVisualSetting` with `constellationArt3d|1` enables the preview;
`constellationArt3d|0` restores illustrations. `getConstellationArtStatus` reports
the loaded geometry and actual mode. The setting persists locally.

HarmonyOS upgrades copy these resources atomically before Qt starts. On a future
mesh revision, bump `.bundled_v1` in `refreshConstellationModels` as well as
regenerating this manifest; resource-build synchronization compares the manifest.
